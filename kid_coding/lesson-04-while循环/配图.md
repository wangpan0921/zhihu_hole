## 图3【概念图·必配】while 三要素流程图（excalidraw）
- **插入位置**：「while 循环长什么样」讲三要素处
- 画一个自上而下 + 回环的流程：
  - 顶部矩形：`① 初值：zombies = 0`（蓝色）
  - 向下箭头进入菱形判断框：`② 条件：zombies < 3 ?`（黄色）
  - 菱形右侧标 `否 → 结束`，右边画一个绿色 `结束` 圆角矩形。
  - 菱形下方标 `是`，箭头进入矩形：`③ 更新 + 循环体：zombies += 1；print(...)`（粉色）
  - 从这个矩形画一条向左向上的回环箭头，回到菱形判断框，箭头上标注「再检查一遍」。
  - 顶部标题：`while 的三件套：初值 / 条件 / 更新`
  - 底部小字：`三样缺一不可，尤其别忘"更新"！`
- Export PNG。

## 图4【运行截图·必配】刷僵尸计数运行截图
- **插入位置**：「while 循环长什么样」输出结果处
- 用在线编辑器（https://www.online-python.com 或 https://pythontutor.com），粘贴：
  ```python
  zombies = 0
  while zombies < 3:
      zombies = zombies + 1
      print("刷出第", zombies, "只僵尸")
  ```
- 运行并截「代码 + 输出」整屏，输出应正好 3 行。字号调大，保持与前三课同一编辑器与配色。
- 也可用 `./venv/bin/python scripts/kid_coding_images.py --lesson 4` 自动生成本课所有代码/终端图。

## 图5【概念图·必配】死循环警示图（excalidraw）
- **插入位置**：「死循环：忘了更新，程序就疯了」节
- 画一个"闭环"来强调无出口：
  - 中央画一个红色环形箭头（首尾相连），环里写 `zombies = 0`「永远不变」。
  - 环外用小字标注 `while zombies < 3:` 和 `print("刷出第 0 只僵尸")`，箭头指向环。
  - 环的旁边画一个惊恐表情 emoji 和文字气泡：`停不下来了！`
  - 底部提示条：`❗ 找不到一行"让条件靠近不成立"→ 死循环`
  - 右下角画一个红色按钮 `Ctrl+C 强停`。
  - 顶部标题：`死循环 = 电脑陷在原地打转`
- 用红色系配色制造警示感 → Export PNG。

## 图6【运行截图·加分】被咬到死的回合数
- **插入位置**：「用 while 干件有用的事」处
- 在线编辑器运行并截图：
  ```python
  hp = 20
  turn = 0

  while hp > 0:
      turn = turn + 1
      hp = hp - 3
      print("第", turn, "回合结束，剩余血量：", hp)

  print("史蒂夫倒下了……坚持了", turn, "回合")
  ```
- 输出应为「第 1..7 回合 + 倒下了」共 8 行。
- 加分做法：再截一张 pythontutor 单步执行图，展示 `hp` 变量一格一格从 20 变到 -1 的过程，突出"while 每轮怎么走"的可视化。
