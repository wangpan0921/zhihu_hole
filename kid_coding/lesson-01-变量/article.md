# 给史蒂夫记一本账：三行代码，看懂程序员的"记忆魔法"

> 这是《我的世界里学编程》系列的第 1 篇。不需要任何基础，你只要玩过、或者见过别人玩《我的世界》就够了。我们的目标很远大——一路通向信息学奥赛；但今天的目标很小——让你写出人生第一行"活"的代码。

## 先问你一个问题

你在《我的世界》里辛辛苦苦挖了一晚上，血量还剩多少？身上背了几个金锭？手里的剑还能砍几下？

这些数字有个共同点：**它们随时在变**。

血量会掉、金币会涨、天会黑。游戏之所以"活着"，就是因为它无时无刻不在记录和更新这一大堆数字。

那么问题来了——**游戏是怎么"记住"这些数字的？**

答案就是今天的主角：**变量（variable）**。

## 变量：一个贴了标签的箱子

想象你面前有一排箱子。你拿一张便利贴，写上"血量"，贴在其中一个箱子上，然后往里面放一个数字 `20`。

以后不管什么时候，只要你喊一声"血量"，就能立刻找到这个箱子，看看里面装的是几。

这，就是变量。

在代码里，创建这个箱子只要一行：

```python
hp = 20
```

翻译成人话：**"造一个叫 hp 的箱子，往里面放个 20。"**

（hp 是 Health Point 的缩写，游戏玩家的老朋友了。）

那个 `=` 不念"等于"，念"放进去"。方向是从右往左：把右边的 `20`，放进左边的 `hp`。记住这个方向，后面你会省很多事。

## 我们来给史蒂夫开个户

光有血量太单调，给我们的主角史蒂夫建一套完整的"家底"：

```python
name = "史蒂夫"
hp = 20        # 血量
gold = 0       # 金币，一开始是穷光蛋
```

注意两件事：

第一，`name` 里放的是文字 `"史蒂夫"`，要用**引号**包起来；`hp` 里放的是数字 `20`，**不用引号**。这是程序员和电脑之间的暗号——加了引号的是"文字"，不加的是"数字"，电脑靠这个区分它俩。

第二，那个 `#` 号后面的字是**注释**，是写给人看的悄悄话，电脑会自动跳过。你可以在这儿写任何提醒自己的话，电脑当没看见。

## 让电脑"开口说话"

家底记好了，怎么让它显示出来？用 `print`：

```python
name = "史蒂夫"
hp = 20

print(name, "现在的血量是", hp)
```

运行一下，屏幕上会出现：

```
史蒂夫 现在的血量是 20
```

`print` 就是"打印到屏幕上"，它是你和程序之间的第一扇窗户。括号里想显示啥就放啥，用逗号隔开，文字要加引号，变量直接写名字。

## 见证奇迹：数字会变了

前面我说变量的灵魂是"会变"。现在让它变给你看。

史蒂夫打了个僵尸，爆出 10 个金币：

```python
gold = 0
print("捡钱之前：", gold)

gold = gold + 10      # 关键的一行
print("捡钱之后：", gold)
```

输出：

```
捡钱之前： 0
捡钱之后： 10
```

重点看这一行：

```python
gold = gold + 10
```

第一次见它，很多人会当场懵：**"gold 怎么能等于 gold 加 10？这不成悖论了吗？"**

别急，还记得我们说过 `=` 不念"等于"、念"放进去"、方向从右往左吗？现在它救场了：

> 先算**右边**：`gold + 10`，也就是 `0 + 10`，等于 `10`。
> 再把这个 `10`，**放进左边**的 `gold` 箱子里。
> 于是 gold 就从 0 变成了 10。

说白了就是：**"把箱子里现在的钱掏出来，加上 10，再塞回去。"**

你在游戏里每一次捡金币、每一次掉血、每一次经验增长，背后都是这么一行朴实无华的代码在默默干活。

## 最后，让程序"认识你"

到目前为止都是我们单方面告诉电脑数字。现在，让电脑反过来问你一句。用 `input`：

```python
player = input("请输入你的角色名：")
print("欢迎来到我的世界，", player, "！")
print("祝你今晚别被僵尸偷家。")
```

运行后，屏幕会停下来等你打字。你输入"我的名字"，敲回车，它就会回你：

```
欢迎来到我的世界， 我的名字 ！
祝你今晚别被僵尸偷家。
```

那一刻，你写的程序**第一次和你对话了**。这不是别人做好的游戏，是你亲手让它开口的。这种感觉，值得你记住。

## 今天你学会了

- **变量**：贴了标签的箱子，用来存会变化的数据（血量、金币、名字）
- **`=`**：不是"等于"，是"把右边放进左边"
- **文字加引号，数字不加**
- **`print`**：让电脑把东西显示到屏幕上
- **`input`**：让电脑停下来，听你说话
- **`#`**：写给人看的悄悄话，电脑会跳过

就这么点东西，你已经掌握了所有游戏、所有软件最底层的地基。真的，不夸张——再厉害的程序，扒到最底下，也是一个个箱子里的数字在变来变去。
