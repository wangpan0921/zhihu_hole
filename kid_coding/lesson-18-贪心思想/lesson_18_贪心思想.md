# 第 18 篇：背包怎么装最划算？——每一步都挑「当下最赚」的那一堆

> 这是《我的世界里学编程》系列的第 18 篇，**第三阶段·算法关**的第 4 课。**上期回顾**：上一课我们请出了 **广搜 BFS**——「像水波纹一样一圈一圈往外扩，第一次碰到出口的那一圈就是最短距离」——史蒂夫赶在天黑前稳稳回家了。**但**，BFS 和 DFS 有一个共同的毛病——**它们只回答「能不能到、几步到」，不回答「值不值、赚不赚」**。**今天**，史蒂夫刚从末影龙巢穴里刨出一堆矿粉，背包却只装得下 20 公斤，**怎么装才最划算？** 请出算法界最狡猾也最诱人的一招——**贪心（Greedy）**——翻译成人话：**「每一步都挑当下看起来最赚的那一个，不回头也不推演」**。听起来像抄近路，却在无数场景里恰好就是最优解；而在另一些场景里，它会**当场翻车**——今天我们让它翻一次，把「什么时候能贪、什么时候不能」的边界钉死。

## 先猜猜看

老规矩，先别急着往下拉。看这段代码——**背包最多能装出多少价值？屏幕最后会打印几？**

```python
# 三箱散装矿粉，「散装」= 可以只装一部分
weights = [10, 20, 30]       # 每箱的重量（kg）
values  = [60, 100, 120]     # 每箱的价值
capacity = 20                # 背包最多装 20 kg

# 第 1 步：算每箱的「性价比 = 价值 / 重量」
ratio = [values[i] / weights[i] for i in range(3)]
# 第 2 步：按性价比从高到低，排出装箱顺序
order = sorted(range(3), key=lambda i: ratio[i], reverse=True)

total = 0
remain = capacity
for i in order:
    if weights[i] <= remain:
        total += values[i]                        # 整箱装下
        remain -= weights[i]
    else:
        total += values[i] * remain / weights[i]  # 装不下整箱，按剩余容量比例拿
        remain = 0
        break

print("最多能装的价值：", total)
```

（提示：`sorted(..., key=..., reverse=True)`——**按某个规则从大到小排序**——第 8 课「按稀有度排列你的战利品」讲过；`key=lambda i: ratio[i]` 是**「按 `ratio[i]` 的大小比较」**的意思。`[... for i in range(3)]` 是「循环一遍生成一个列表」的偷懒写法，叫**列表推导（list comprehension）**。`total += x` 就是 `total = total + x`——「往 total 里再加一份 x」。)

猜好数字记在心里，等下 I-do 对答案。

## 一句话接主线

史蒂夫刚从末影龙的巢穴里刨出三大箱散装矿粉——**铁矿粉一箱 10 公斤价值 60 经验、金矿粉一箱 20 公斤价值 100 经验、钻石粉一箱 30 公斤价值 120 经验**——可他的背包最多只塞得下 20 公斤。他犯了愁：**每一箱都想要，可背包不答应**。上一课 BFS 那套「一圈一圈往外摊」在这儿完全用不上——**这次要回答的不是「几步到」，是「怎么装最赚」**。我们凑过去说：**你甩掉「把所有可能都试一遍」的笨办法，改用一个狡猾的直觉——「每一次挑，都挑当下每公斤最值钱的那一堆」，把最贵的每一克先塞进包，再拿次贵的填缝**。这就是**贪心思想（Greedy）**——**信奥赛里 CSP-J 的入门难题、活动安排、找零、Huffman 编码……全都是它的地盘**，也是通向下一课**动态规划**的必经踏板。

## 从「每一克最贵」讲起（I-do）

先想清楚**「贪心」的名字从哪儿来**——**「贪」= 只看眼前，只挑当下最赚**；**「心」= 心里就这一杆秤，专门定「什么叫最赚」**。合起来一句话：**面前有一堆选项时，永远挑「按某个标准衡量」当下最好的那一个，选完就往前走，绝不回头，也不推演往后**。

问题来了：**「最好」到底按什么标准？** 三箱矿粉摆你面前，你会先拿哪箱？

- **按总价值**：钻石粉最贵（120），先拿它？——一箱就 30 kg，压根装不下，只能拿一部分。
- **按重量小**：铁矿粉最轻（10 kg），先拿它？——听着不像「贪」，倒像「怯」。
- **按每公斤单价**：**看性价比**。**这才是「贪」的关键**。

每箱的「性价比 = 价值 / 重量」：

- **铁矿粉**：10 kg / 60 分 → 每 kg **6** 分
- **金矿粉**：20 kg / 100 分 → 每 kg **5** 分
- **钻石粉**：30 kg / 120 分 → 每 kg **4** 分

翻译成人话：**「铁矿粉每公斤 6 分，是三箱里最贵的一克；金次之，钻最便宜」**。你没看错，**钻石粉论一整箱最贵，论每公斤反而最便宜**——这就是「性价比」和「总价」的差别。

**贪心的策略**是：**先把「每公斤最贵」的那一箱能塞多少塞多少，再把次贵的塞进剩下的缝**。**因为矿粉是散装、可以只拿一部分**——**只要包里每一克都是当下能拿到的最贵那一克，总价值就一定最高**。这种「装的东西可以切一部分」的背包，有个专门的名字叫**分数背包（Fractional Knapsack）**——翻译成人话：**「箱子可以只拿一半、只拿三分之一」的背包**。

回到你刚才猜过的代码，我把关键点圈出来：

```python
weights = [10, 20, 30]
values  = [60, 100, 120]
capacity = 20

ratio = [values[i] / weights[i] for i in range(3)]           # ① 每箱的性价比：[6.0, 5.0, 4.0]
order = sorted(range(3), key=lambda i: ratio[i], reverse=True)  # ② 按性价比高→低排下标：[0, 1, 2]

total = 0
remain = capacity
for i in order:                                              # ③ 按贪心顺序，一箱一箱试
    if weights[i] <= remain:
        total += values[i]                                   # ④ 装得下：整箱全塞
        remain -= weights[i]
    else:
        total += values[i] * remain / weights[i]             # ⑤ 装不下：只拿装得下的那一部分
        remain = 0
        break                                                #    背包已满，收工

print("最多能装的价值：", total)
```

- **① `ratio`**——**每箱的「每公斤价值」**。这是**贪心的秤**——**所有选项都拉到「每 kg 值几分」这个尺度上比**。
- **② `sorted(range(3), key=..., reverse=True)`**——**「按性价比从大到小」排出下标顺序**。这里 `sorted` 返回的不是排好的 ratio，而是**「哪个下标该排第一、哪个第二」**——`[0, 1, 2]` 表示先拿第 0 箱（铁）、再第 1 箱（金）、最后第 2 箱（钻）。**这一步是贪心的心脏——决定「谁先谁后」**。
- **③ `for i in order:`**——**照排好的顺序一箱一箱试**。每一步都在「当下最赚的那箱」上做选择——**这就是「贪」**。
- **④ 装得下 → 整箱塞**：**性价比最高的能塞满就塞满，一克也不浪费**。
- **⑤ 装不下 → 按比例切一部分**：**剩多少容量，就按 `remain / weights[i]` 的比例拿这箱的一部分**。**这一步依赖「分数背包」这个前提——箱子可以拆散**。装完 `break`——背包满了就走人，后面性价比更低的连试都不用试。

现在跑一下，输出：

```
最多能装的价值： 110.0
```

**110 分**。把过程画出来看更清楚：

```
背包容量：20 kg      当前收益：0

第 1 步：铁矿粉（性价比 6）
  整箱 10 kg 装得下 → 全塞
  ┌────────┐             剩余容量：20 - 10 = 10 kg
  │ 铁 10  │             收益：0 + 60 = 60
  └────────┘

第 2 步：金矿粉（性价比 5）
  整箱 20 kg > 剩余 10 kg → 只切一半
  ┌────────┬────────┐    剩余容量：0
  │ 铁 10  │ 金 10  │    收益：60 + 100 × 10/20
  └────────┴────────┘         = 60 + 50 = 110

第 3 步：钻石粉（性价比 4）
  背包已满 → break，连试都不用
```

**110 分，一分不多**。如果你刚才猜的正是 110（哪怕不知道是 110.0），说明你已经在心里预跑了一遍「贪」。

**为什么贪心在这里就是最优？** 想象你反悔：把最后那 10 kg 的金矿粉换成任何别的组合——铁只有 10 kg 已经拿完了，钻的每 kg 只值 4 分（比金的 5 分还便宜）——**换任何一克进去，总价都会掉**。**只要每一克都是当下最贵的，总价就一定是最高的**——这句话是**分数背包里贪心成立的「一句话证明」**。

## 一起改改看（We-do）

**实验：把「散装」改成「整箱」，看贪心当场翻车**。矿粉是能切散的，可假如三箱都是**整块的、不可切分**呢——比如一整颗末影水晶、一整根末影棒、一整枚龙蛋？**要么整个拿走、要么一点都别拿**——这种背包叫 **0-1 背包（0/1 Knapsack）**——翻译成人话：**「0 = 不拿，1 = 拿走，没有中间态」**。

代码只改两行——把 `else` 分支里的「按比例拿」删掉，换成「装不下就跳过下一箱」：

```python
weights = [10, 20, 30]
values  = [60, 100, 120]
capacity = 20

ratio = [values[i] / weights[i] for i in range(3)]
order = sorted(range(3), key=lambda i: ratio[i], reverse=True)

total = 0
remain = capacity
for i in order:
    if weights[i] <= remain:
        total += values[i]
        remain -= weights[i]
    else:
        continue                       # ← 唯一改动：装不下不切,直接跳过这一箱

print("最多能装的价值：", total)
```

**先别运行，先预测**——**总价会变吗？会变大还是变小？** 把答案写在纸上（心里默一遍也行）。

……

跑一下：

```
最多能装的价值： 60
```

**60！从 110 掉到 60**——**近乎腰斩**。发生了什么？

- 贪心第 1 步：铁矿粉（性价比最高）10 kg 塞进包，剩 10 kg。
- 贪心第 2 步：金矿粉 20 kg 装不下——**不能切，只能跳过**。
- 贪心第 3 步：钻石粉 30 kg 更装不下——**也跳过**。
- 收工：60 分。

**可最优答案根本不是 60**。用脚趾头列一列 0-1 背包所有可行组合（`✓` 拿、`✗` 不拿）：

- 铁 ✗ 金 ✗ 钻 ✗ → 0 kg，**0 分**
- 铁 ✓ 金 ✗ 钻 ✗ → 10 kg，**60 分** ← **贪心停在这**
- 铁 ✗ 金 ✓ 钻 ✗ → 20 kg，**100 分** ← **真正的最优**
- 铁 ✗ 金 ✗ 钻 ✓ → 30 kg，超载 ✗
- 铁 ✓ 金 ✓ 钻 ✗ → 30 kg，超载 ✗
- 其余带钻石的组合更重，**全部超载**

**真正的最优是「放弃铁矿粉、整箱扛走金矿粉」——100 分**。贪心却因为**只看眼前的「每 kg 最贵」**——**先把 10 kg 白白填给了铁**——**再回头时金已经装不下了**。

**翻译成人话**：**在 0-1 背包里，贪心「近视」——它只看一步之内最赚，看不到「为了给后面那个大块头留位置，我该忍住不拿这个小便宜」**。

这就把「什么时候能贪、什么时候不能」的**边界**钉死了：

- **可以切分（分数背包）** → **贪心一定最优**——每一克都换成当下最贵的，永远最赚。
- **不可切分（0-1 背包）** → **贪心可能翻车**——为了给未来的大块头留位置，有时得放弃眼前的小便宜。这时候得请出**下一课的动态规划（DP）**——**「我不只看当下，我把所有可能都想一遍，只是聪明地想」**。

**上一课我们说 DFS 会「叫太深」、BFS 会「队列爆炸」——那都是「机制上的翻车」——程序直接罢工，你一眼就能看见**。**贪心的翻车不一样——它不报错、不死循环、不爆内存**——**它给你一个看似合理的答案，你甚至看不出错在哪，直到题目样例不过**。**这就是贪心最阴险的地方**。所以信奥赛里用贪心之前，**总得先证明「这题真的能贪」**——不然你会在测试点上安静地丢分。

## 今天你学会了

- **贪心思想（Greedy）**——翻译成人话：**「每一步都挑当下看起来最赚的那一个，不回头也不推演」**。**「贪」= 只看眼前**，**「心」= 心里只有一杆秤，专门定「最赚」**。
- **贪心两步走**：**① 想清楚「秤」是什么**（性价比？总价？重量？）；**② 按这杆秤排好顺序，一路挑到底**。**选对秤 = 贪对**，**选错秤 = 贪偏**。
- **分数背包（Fractional Knapsack）**——**箱子可以只拿一部分**——**「按性价比从高到低」的贪心一定最优**。**一句话证明**：**只要包里每一克都是当下最贵，总价就一定最高**。
- **0-1 背包（0/1 Knapsack）**——**要么整箱拿、要么一点不拿**——**贪心可能翻车**。因为它「近视」——**看不见「忍住眼前小便宜、给后面大块头留位置」的可能**。
- **贪心的翻车姿势**——**不报错、不死循环、不爆内存**——**只是安静地给你一个不最优的答案**。**这是它比 DFS / BFS 更阴险的地方**。
- **能不能贪的边界**——**能切分 / 换个视角依然最优 / 能给出严谨证明**——**这三条撑得住，才敢贪**；**撑不住，得让位给下一课的动态规划**。
- **贪心 vs BFS / DFS 的心智模型**：
  - **DFS / BFS**：**穷举**——把所有可能一个个走一遍，问「能不能到」「几步能到」。
  - **贪心**：**抄近路**——不问所有可能，只信一杆秤，一路挑到底，问「怎样最赚」。
  - **能抄近路时，贪心又快又对；不能抄时，它会悄悄给你错答案**。

学到这里，你的程序第一次学会了**「衡量哪个选项当下最划算」**——**恭喜你，史蒂夫背包里从此塞的都是最贵的东西**（**只要它们是散装的**）。

## 下期预告

贪心是一把**又快又利、但只在特定地形上好使**的刀——它靠「一杆秤 + 不回头」跑得飞快，也因为「不回头」在 0-1 背包上摔了个大跟头。**信奥赛里更多的题**长这样：**「不能切分、每一步都有多个选择、还得回头改主意」**——这时候贪心不够用，穷举又超时。**下一课**（第 19 篇）——**通关攻略的最优解 · 动态规划入门（DP）**，我们请出算法界的「记账高手」——**「把每个小问题的最优解都存下来，大问题就是几个小问题拼出来的」**——它是贪心的严肃升级版：**不再"一步到底不回头"，而是"每一步都从此前所有小问题的答卷里挑最好的接着写"**。0-1 背包这道贪心翻过车的题，下一课我们让它老老实实交出 100 分的正确答案。
