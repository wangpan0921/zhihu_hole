# 读音替换词典（只影响配音，不影响字幕文字）。
# 每行：原词 => 朗读替换   用同音字纠正多音字或符号读音；# 开头为注释。
# 用 => 分隔，这样原词里含 = 号（如 ==、>=、<=、!=）也不会被切错。
# 注意：不要用裸的「>」「<」做原词，会把 >= <= 里的符号也换掉；请用「符号+词」或整串。

一行 => 一航

# 比较符号：整串（用于摘要页「> < >= <= == !=」这种连排）
> < >= <= == != => 大于、小于、大于等于、小于等于、等于、不等于

# 比较符号：符号+词（用于讲解页，符号紧跟中文词）
>= 大于等于 => 大于等于
<= 小于等于 => 小于等于
== 等于 => 等于
!= 不等于 => 不等于
> 大于 => 大于
< 小于 => 小于

# 关键字/其它读音
elif => else if
else / elif => else 或者 else if
True / False => True 或 False
