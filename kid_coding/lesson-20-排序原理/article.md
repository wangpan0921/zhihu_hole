## 先猜猜看

史蒂夫捡到四块矿石，价值分别是 `7、2、9、4`。下面这段程序最后会打印什么？是已经排好的 `[2, 4, 7, 9]`，还是原来的顺序？

```python
loot = [7, 2, 9, 4]

for i in range(len(loot) - 1):
    for j in range(len(loot) - 1 - i):
        if loot[j] > loot[j + 1]:
            loot[j], loot[j + 1] = loot[j + 1], loot[j]

print(loot)
```

先把你的预测写下来。注意这里出现了**嵌套循环**，翻译成人话：**“一个循环里面再套一个循环，外层管大轮次，内层管这一轮的逐格检查。”** 还有**交换**，翻译成人话：**“把两个箱子里的东西互换位置。”** 等 I-do 讲完，再回头检查你的答案。

## 游戏场景：矿石不能乱成一锅粥

背包里有煤炭、铁、金和钻石，按价值乱放，找一块钻石要翻半天。**排序**（sorting），翻译成人话：**“按照某个规则，把一堆东西重新排成队。”** 我们先学最直观的**冒泡排序**（bubble sort），翻译成人话：**“让较大的数像气泡一样，一步一步冒到队伍右边。”**

### I-do：冒泡排序，比较相邻的两块矿

```python
loot = [7, 2, 9, 4]

# 外层：一共要做 len(loot) - 1 轮
for i in range(len(loot) - 1):
    # 内层：比较相邻的两个位置
    for j in range(len(loot) - 1 - i):
        if loot[j] > loot[j + 1]:
            # 交换：左边更大，就把它换到右边
            loot[j], loot[j + 1] = loot[j + 1], loot[j]

print("从小到大：", loot)
```

运行结果：

```text
从小到大： [2, 4, 7, 9]
```

第一轮从左往右看：`7` 和 `2` 换位，`7` 和 `9` 不换，`9` 和 `4` 再换。于是最大的 `9` 一路“冒”到最右边。下一轮不用再看最后一格，因为它已经就位。`i` 是**轮次**，翻译成人话：**“已经把几块最大的矿石送到右侧固定位置。”** `j` 是**下标**，翻译成人话：**“当前正在检查队伍里的第几个位置。”**

这行交换代码很短：

```python
loot[j], loot[j + 1] = loot[j + 1], loot[j]
```

它叫**多重赋值**，翻译成人话：**“不用额外箱子，就把左右两个位置同时换好。”** 如果你更喜欢“有三个箱子”的写法，也可以这样写：

```python
temp = loot[j]
loot[j] = loot[j + 1]
loot[j + 1] = temp
```

两种写法结果一样。程序员喜欢第一种，是因为少写一行，少一个可能写错的地方。

### 再看一种思路：选择排序

冒泡排序每次比较邻居；**选择排序**（selection sort），翻译成人话：**“每一轮先在剩下的队伍里挑出最小的，再把它放到队首。”**

```python
loot = [7, 2, 9, 4]

for i in range(len(loot) - 1):
    min_index = i
    for j in range(i + 1, len(loot)):
        if loot[j] < loot[min_index]:
            min_index = j

    loot[i], loot[min_index] = loot[min_index], loot[i]

print("选择排序：", loot)
```

`min_index` 是**最小值下标**，翻译成人话：**“先记住目前发现的最小矿石在哪一格。”** 这一轮走完，再把它和第 `i` 格交换。冒泡像“邻居比赛”，选择像“全场选冠军”。两者都能排好，但思考路线不同。

### 电脑已经有现成工具：`sort` 和 `sorted`

手写排序是为了看懂原理。真正写程序时，Python 自带**方法**，翻译成人话：**“某种数据自己会做的一项动作。”**

```python
loot = [7, 2, 9, 4]

loot.sort()
print("sort 排好后：", loot)

new_loot = sorted([7, 2, 9, 4])
print("sorted 排好后：", new_loot)
```

输出：

```text
sort 排好后： [2, 4, 7, 9]
sorted 排好后： [2, 4, 7, 9]
```

区别是：`sort()` 会**直接修改原列表**，翻译成人话：**“就在原来的背包里重新摆放。”** `sorted()` 会**返回一个新列表**，翻译成人话：**“复制一份排好队的背包，原来的那份还保持不变。”**

```python
loot = [7, 2, 9, 4]
sorted_loot = sorted(loot)

print("原来的背包：", loot)
print("新的有序背包：", sorted_loot)
```

## 一起改改看（We-do）

现在把 I-do 的冒泡排序改成**从大到小**，让最贵的钻石先出现。只改一处：把比较符号从 `>` 换成 `<`。

```python
loot = [7, 2, 9, 4]

for i in range(len(loot) - 1):
    for j in range(len(loot) - 1 - i):
        if loot[j] < loot[j + 1]:
            loot[j], loot[j + 1] = loot[j + 1], loot[j]

print("从大到小：", loot)
```

**先预测**：最后一行会是什么？

```text
从大到小： [9, 7, 4, 2]
```

揭晓：答案就是 `[9, 7, 4, 2]`。因为现在只有“左边更小”时才交换，小的数会一路移动到右边，大的数被留在左边。这个小改动说明，排序规则常常只藏在一个比较符号里。**升序**，翻译成人话：**“从小到大。”** **降序**，翻译成人话：**“从大到小。”**

## 今天你学会了

- **排序**：按规则重新排队；升序是小到大，降序是大到小。
- **冒泡排序**：比较相邻元素，把较大的数逐轮推到右边。
- **选择排序**：每轮找出剩余元素里的最小值，放到当前队首。
- **交换**：互换两个位置的内容；Python 可以用多重赋值一行完成。
- **`sort()`**：修改原列表并排序。
- **`sorted()`**：生成一个新的有序列表，不改变原列表。
- **嵌套循环**：循环套循环；外层数轮次，内层完成一轮比较。

冒泡和选择都属于**简单排序**，翻译成人话：**“代码容易看懂，但数据很多时会慢。”** 它们通常需要大约 `n × n` 次比较，叫做**时间复杂度 O(n²)**，翻译成人话：**“数据量变成两倍，工作量可能接近四倍。”** Python 的 `sort()` 内部用了更成熟的算法，翻译成人话：**“把大量整理工作交给已经优化过的工具。”** 这也是为什么我们要先手写原理，再放心使用工具。
