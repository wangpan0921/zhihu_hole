# 第 17 篇：最短的回家路：像水波一圈一圈把最短距离摊开

> 这是《我的世界里学编程》系列的第 17 篇，**第三阶段·算法关**的第 3 课。**上期回顾**：上一课我们请出了 **深搜 DFS**——「一条路走到黑，走不通再退回来试另一条」——史蒂夫总算能在方格迷宫里自动寻路了。**但**，DFS 找到的**不一定是最短的那条**——它只挑一条路先钻到底，能通就好，长短不管。**今天**，天快黑了，史蒂夫要赶在僵尸出门之前回家——他要的是**最短路**：**不绕远、不走冤枉步**。请出 DFS 的孪生兄弟——**广搜 BFS**（Breadth-First Search，广度优先搜索）——翻译成人话：**「像水波纹一样一圈一圈往外扩，第一次碰到出口的那一圈，就是最短距离」**。

## 先猜猜看

老规矩，先别急着往下拉。看下面这张迷宫和这段短代码——**史蒂夫最短要走几步才能从 S 到 E？屏幕最后会打印几？**

```python
from collections import deque

maze = [
    ['S', '.', '.', '.'],
    ['.', '#', '#', '.'],
    ['.', '.', '.', 'E'],
]

ROWS = len(maze)
COLS = len(maze[0])
dist = [[-1] * COLS for _ in range(ROWS)]

q = deque()
q.append((0, 0))
dist[0][0] = 0

while q:
    r, c = q.popleft()
    if maze[r][c] == 'E':
        print("最短步数：", dist[r][c])
        break
    for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:   # 上、下、左、右
        nr, nc = r + dr, c + dc
        if not (0 <= nr < ROWS and 0 <= nc < COLS):
            continue
        if maze[nr][nc] == '#':
            continue
        if dist[nr][nc] != -1:
            continue
        dist[nr][nc] = dist[r][c] + 1
        q.append((nr, nc))
```

（提示：`deque` 就是**队列**——**先进先出**，像食堂排队。`dist[r][c]` 是「从起点走到 (r, c) 用了几步」，一开始全填 `-1` 表示「还没到过」。`(dr, dc)` 是「方向偏移」，四个方向就四对数。`S` 是起点、`E` 是出口、`#` 是墙、`.` 是能走的空地——和上一课迷宫的记号完全一致。）

猜好步数记在心里，等下 I-do 一起对答案。

## 一句话接主线

太阳快落山了，史蒂夫背包里塞满今晚要抢救回来的物资——**再不回家就要被僵尸拦路**。他望着面前这张方格地图犯了愁：上一课他好不容易学会了「一条路走到黑」的 DFS，可 DFS 找到的路**可能绕远了半张地图**。他要**最短的**——**不绕远、不走冤枉步**。我们凑过去说：**你换个思路——不再选一条路一钻到底，而是像往水塘扔一颗石子，水波纹一圈一圈往外荡，一圈就是「多走一步」；第一次碰到家门的那一圈，就是最短距离**。这就是**广搜 BFS**——**信奥赛里网格最短路、图上最少步数，九成入门题都靠它开局**，和上一课的 DFS 是**图论入门的两把万能钥匙**。

## 从「一颗石子丢进水塘」讲起（I-do）

先想清楚**「广搜」的名字从哪儿来**——**「广」= 一圈一圈往外摊，「搜」= 挨个格子试一遍**。合起来就一句话：**先把离起点 1 步远的格子全踩一遍，再把 2 步远的踩一遍，再 3 步远、4 步远……** 第一次踩到出口时，当前的圈数就是**最短步数**。

想象你把一颗石子扔进池塘：第 0 圈是石子落点（起点）；第 1 圈是紧挨起点的 4 个邻居（上下左右）；第 2 圈是这 4 个邻居各自再往外一步能到的新格子；第 3 圈继续向外扩一层……**每一圈里的格子和起点的距离都相同**。

问题来了：**「先来的先扩」这件事，DFS 用递归自动帮你做了；BFS 里靠什么保持这个顺序？**——答：**队列（queue）**——**先进先出（FIFO，First In First Out）**——**先排上队的格子先出队去扩它的邻居**。翻译成人话：**「食堂打饭排队，先到先打，不许插队」**。

回到你刚才猜过的代码，我把关键点圈出来：

```python
from collections import deque                              # ① 队列工具：先进先出的箱子

maze = [
    ['S', '.', '.', '.'],
    ['.', '#', '#', '.'],
    ['.', '.', '.', 'E'],
]
ROWS = len(maze)
COLS = len(maze[0])
dist = [[-1] * COLS for _ in range(ROWS)]                  # ② 记步数，-1 = 还没到过

q = deque()
q.append((0, 0))                                           # ③ 起点先排上队
dist[0][0] = 0                                             #    自己到自己是 0 步

while q:                                                   # ④ 队里还有人排队，就继续
    r, c = q.popleft()                                     # ⑤ 队首出队一个格子，去扩它的邻居
    if maze[r][c] == 'E':
        print("最短步数：", dist[r][c])
        break
    for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:       # ⑥ 上下左右四个方向
        nr, nc = r + dr, c + dc
        if not (0 <= nr < ROWS and 0 <= nc < COLS):        # ⑦ 三道门：越界？
            continue
        if maze[nr][nc] == '#':                            #    三道门：撞墙？
            continue
        if dist[nr][nc] != -1:                             #    三道门：已经到过？
            continue
        dist[nr][nc] = dist[r][c] + 1                      # ⑧ 邻居的步数 = 我 + 1
        q.append((nr, nc))                                 # ⑨ 邻居排到队尾
```

- **① `deque`（双端队列，double-ended queue）**——翻译成人话：**「两头都能进出的箱子，但我们只用两个动作：队尾进、队首出」**。用 `append` 排到队尾，`popleft` 从队首取——**先来的先出**。
- **② `dist[r][c]`**——翻译成人话：**「从起点走到这一格用了几步」**。一开始全填 `-1` 意思是「还没到过」。**它一身兼两职**：既是**步数记录本**，又是**这一课的 visited（已访问）**——因为「`dist == -1`」就等价于上一课的「还没贴便利贴」。
- **③ 起点先排上队**——**距离设为 0，自己到自己 0 步**。
- **④ `while q:`**——**队里还有格子就继续扩**；**队空 = 该扩的全扩完了**。
- **⑤ `popleft()`**——**从队首拿一个格子出来「扩」它**。**「先排上队的先被处理」——这一句是 BFS 的心跳**。（别用 `pop()`——那是从队尾取，队列就变成了栈，BFS 就退化成 DFS 了。）
- **⑥ 四个方向**——用 `[(-1,0), (1,0), (0,-1), (0,1)]` 一次性列全，配合 `for` 遍历，比 DFS 那种 `if dfs(...)` 四连击看起来清爽多了。
- **⑦ 三道门**——**不越界、不撞墙、没到过**——**和上一课 DFS 那三道门一模一样**，只是这里把「没到过」写成了「`dist == -1`」。
- **⑧ 邻居的步数 = 我 + 1**——**这就是 BFS 的灵魂**：**先入队的距离小，后入队的距离大，永远保持「近的先扩，远的后扩」**。所以只要一到出口，那个数就是**最短步数**——**没有之一**。
- **⑨ 邻居排到队尾**——**排在后面的人晚一圈才被扩**——**「一圈一圈往外摊」的秩序，靠这一句维护**。

现在跑一下，输出：

```
最短步数： 5
```

对照迷宫看一眼（记住 `(r, c)` 是**行号, 列号**，都从 0 数）：

```
列号：   0    1    2    3
行 0： [ S ][ . ][ . ][ . ]
行 1： [ . ][ # ][ # ][ . ]
行 2： [ . ][ . ][ . ][ E ]
```

把水波纹画出来看更清楚（每格上写的是 `dist`，`#` 是墙，永远到不了）：

```
第 0 圈：   [0][ ][ ][ ]
           [ ][#][#][ ]
           [ ][ ][ ][ ]

第 1 圈：   [0][1][ ][ ]
           [1][#][#][ ]
           [ ][ ][ ][ ]

第 2 圈：   [0][1][2][ ]
           [1][#][#][ ]
           [2][ ][ ][ ]

第 3 圈：   [0][1][2][3]
           [1][#][#][ ]
           [2][3][ ][ ]

第 4 圈：   [0][1][2][3]
           [1][#][#][4]
           [2][3][4][ ]

第 5 圈：   [0][1][2][3]
           [1][#][#][4]
           [2][3][4][5]  ← 第一次踩到 E，dist = 5
```

**5 步，一步不多**。走出去的最短路径大概长这样：`(0,0) → (0,1) → (0,2) → (0,3) → (1,3) → (2,3)`——**从上边绕过那堵墙**，一路右到底，再顺着最右列下来。如果你刚才猜的正是 5，说明你已经在心里预跑了一遍水波纹。

**再对比一下上一课**：DFS 只要能通就好——**它有可能一头扎进 (1,0)→(2,0)→(2,1)→(2,2)→(2,3)**，走 5 步同样到达；**也可能**先绕进死胡同再退回来，**多走几步都可能**。**BFS 保证的是「第一次到 E 时，`dist` 就是最短」——不多一步，不多一格**。

## 一起改改看（We-do）

**实验 1：换方向的顺序，最短距离会变吗？** 把方向列表从「上下左右」改成「**右、下、左、上**」——也就是让史蒂夫**先试右手边**——只改中间那一行：

```python
    for dr, dc in [(0, 1), (1, 0), (0, -1), (-1, 0)]:   # 右、下、左、上
```

**先别运行，先预测**——**最短步数会变吗？会变大还是变小？为什么？** 把答案写在纸上（或者心里默一遍也行）。

……

回想上一课：**DFS 里换个方向，走过的格子数就变了**——因为 DFS 是「一条路先钻到底」，先钻哪个方向决定了它先撞进哪条死胡同。**BFS 呢？**

跑一下：

```
最短步数： 5
```

**居然还是 5！** 不管你先扩哪个方向，**每一圈踩到的格子都是同一批，只是顺序不同**。**「一圈一圈往外摊」这件事，不受方向顺序影响**——第一次踩到 E 的那一圈，永远是**最近的那一圈**。

**翻译成人话**：**BFS 给的最短距离是「地图定了就定了」的，和你先试哪边无关**；而 DFS 找到的路径长短会随方向顺序变。**这就是 BFS 比 DFS 靠谱的地方——它给你的答案是「最短」，不是「碰上的第一条」**。

**实验 2：故意把「已经到过」的门拿掉**。回到原版代码，把 BFS 三道门里的最后一道——**`if dist[nr][nc] != -1: continue`** ——**整段删掉**：

```python
        # 三道门只留两道：越界、撞墙。「已经到过」这道故意不检查
        if not (0 <= nr < ROWS and 0 <= nc < COLS):
            continue
        if maze[nr][nc] == '#':
            continue
        # ← 原本这里还有一道 dist == -1 检查，删掉
        dist[nr][nc] = dist[r][c] + 1
        q.append((nr, nc))
```

**先别运行，先猜**：程序还能不能跑？会不会像上一课一样翻车？

……

跑起来，你会发现一个有点意外的结果：**程序没有卡死，仍然输出 `最短步数： 5`**。这是因为这个迷宫的出口可以到达，而且代码一把出口从队首取出来就执行了 `break`。程序在队列真正失控前已经停下来了。

不过，「已经到过」这道门绝不是多余的。删掉它以后，**同一个格子会从不同方向反复入队**，`dist` 里的旧值也会被反复覆盖。给程序加一个计数器，就能看到藏在答案背后的重复工作：

```python
popped = 0                         # 写在 while q: 前面

while q:
    r, c = q.popleft()
    popped += 1
    if maze[r][c] == 'E':
        print("最短步数：", dist[r][c])
        print("出队次数：", popped)
        print("队列中还剩：", len(q))
        break
    # 下面的代码不变
```

在这张地图和原来的方向顺序下，保留第三道门时，出口出队前一共处理 **10** 个格子，队列中还剩 **0** 个；删掉第三道门后，却处理了 **47** 次，队列中还留着 **46** 个重复项。**答案这次碰巧没变，工作量却已经多了很多。**

如果地图里有环，而且**出口不可达**，或者程序不在出口处 `break`、而是想遍历完整张地图，那么没有「已经到过」检查时，格子就会来回入队，队列无法清空。**翻译成人话**：这一次史蒂夫及时走到出口，所以程序停了；但「打过饭的人还能反复排队」仍然会制造大量无用工作，在需要完整搜索时甚至让程序无法结束。

上一课我们说 DFS 有两把刹车：**底**（base case）和**便利贴**（visited）。今天 BFS 的三把刹车也长同一副样子：

- **起点入队 + `dist[起点] = 0`**（开场两件套别忘）
- **邻居的三道门**（不越界、不撞墙、没到过）
- **距离 = 上一格 + 1，然后入队**

**少了其中一环，程序就可能算错、做大量重复工作，或者无法结束。**

## 今天你学会了

- **广搜 BFS（Breadth-First Search，广度优先搜索）**——翻译成人话：**「像水波纹一样一圈一圈往外扩，第一次碰到出口的那一圈，就是最短距离」**。
- **队列 queue**——翻译成人话：**「食堂排队，先到先打，不许插队」**——**先进先出（FIFO）**。用 `from collections import deque`；`append` 排队尾，`popleft` 从队首出。
- **`dist` 数组一身两职**——**既记步数，又当 visited**。一开始全填 `-1`；到某格时填「上一格 + 1」；再用 `dist == -1` 就能判断「没到过」。
- **BFS 的三道门**——**不越界、不撞墙、没到过**——**和 DFS 一样**，只是「没到过」这里写成 `dist == -1`。
- **方向顺序不影响最短距离**——**BFS 的答案是「地图定了就定了」的**；换个方向，只是踩到同一批距离的顺序变了。这是 BFS 比 DFS「稳」的核心。
- **「没到过」检查不能省**——忘写这道门，同一个格子会反复入队。这张地图因为找到出口后立刻 `break`，所以仍会结束并输出 `5`，但出队次数从 **10** 次增加到 **47** 次；若出口不可达且地图中有环，队列还可能永远无法清空。
- **DFS vs BFS 的心智模型**：
  - **DFS**：**纵着钻**——先深后广，靠**递归**；适合「有没有一条路能到」「所有可能怎么枚举」。
  - **BFS**：**横着摊**——先广后深，靠**队列**；适合「最短几步」「最少几层」。
  - **同一张迷宫，DFS 找的是「一条能通的路」，BFS 找的是「最近的那条路」**。

学到这里，你的程序第一次学会了**「找最短路」**——**恭喜你，史蒂夫可以在天黑前稳稳回家了**。

maze = [
    ['S', '.', '#', '.', '.'],

## 下期预告

DFS 会**穷举**每一条路，BFS 会**逐圈摊开**——它们**不问性价比，只问「能不能到」和「几步到」**。可**信奥赛里更多的题**是这样问的：「一个背包只能装 20 公斤，面前一堆材料每样重量和价值不同，**怎么装最划算？**」——这时候「把所有可能都枚举」会超时，「一圈一圈摊开」也用不上。**下一课**（第 18 篇）——**背包怎么装最划算？· 贪心思想**，我们请出算法界最狡猾的一招——**「每一步都挑当下看起来最划算的」**——听起来像走捷径，却在无数场景里恰好就是最优解；而在另一些场景里，它会**当场翻车**——我们也会亲眼看它翻一次，把「什么时候能贪、什么时候不能」的边界钉死。
