## 图3【概念图·加分】`.replace` 必须"接住"（excalidraw）
- **插入位置**：讲 `.replace` 不改原字符串那段
- 画对比两栏：
  - 左栏「❌ 白改」：一台机器（矩形+齿轮）吐出一个字条 `"**苦力怕"` 掉在地上；旁边 msg 箱子里还是原字符串 `"笨蛋苦力怕"`。代码 `msg.replace("笨蛋", "**")` 打红叉。
  - 右栏「✅ 接住了」：同一台机器吐出的字条被一个新箱子 `msg =` 接住；msg 箱子内容变成 `"**苦力怕"`。代码 `msg = msg.replace("笨蛋", "**")` 打绿钩。
  - 顶部标题：`.replace 不会改原字符串，必须用变量接住返回值`
  - 底部注：`就像上一课的 return——不接住，成品就掉地上`。
- 导出 PNG。

## 图4【概念图·必配】切片"含头不含尾"（excalidraw）
- **插入位置**：讲切片语法处
- 顶部代码：`msg = "我的世界真好玩"`
- 中间画一排 7 个方格，每个方格里一个字：`我 的 世 界 真 好 玩`；
  - 方格上方标下标 `0 1 2 3 4 5 6`；
  - 方格下方标负下标 `-7 -6 -5 -4 -3 -2 -1`。
- 下方画 5 组示范，每组一行「代码 → 高亮方格 → 结果」：
  - `msg[0:2]` → 高亮方格 0、1 → 结果 `"我的"`
  - `msg[2:4]` → 高亮方格 2、3 → 结果 `"世界"`
  - `msg[:2]`  → 高亮方格 0、1 → 结果 `"我的"`
  - `msg[4:]`  → 高亮方格 4、5、6 → 结果 `"真好玩"`
  - `msg[-2:]` → 高亮方格 5、6 → 结果 `"好玩"`
- 每组"终点"位置用**虚线红框**表示"到这里但不包含"。
- 顶部大标题：`切片规矩：含头不含尾`
- 底部小字：`起点省略 = 从头；终点省略 = 到尾；负数 = 从右边数`
- 导出 PNG。

## 图5【运行截图·加分】in + replace 组合
- **插入位置**：讲完 `.replace` 多个词那段
- 用 https://www.online-python.com 或 https://pythontutor.com，代码：
  ```python
  msg = "笨蛋苦力怕又来偷家"

  if "笨蛋" in msg:
      print("⚠️ 检测到敏感词")

  clean = msg.replace("笨蛋", "**").replace("偷家", "**")
  print("过滤后：", clean)
  ```
- 输出：
  ```
  ⚠️ 检测到敏感词
  过滤后： **苦力怕又来**
  ```
- 截「代码 + 输出」整屏，字号调大，配色与全系列一致。

## 图6【运行截图·必配】命令识别机
- **插入位置**：「拼成一台命令识别机」节末尾
- 代码：
  ```python
  def parse_command(msg):
      if msg[:1] != "/":
          return "这是普通聊天：" + msg
      space = msg.find(" ")
      if space == -1:
          return "命令：" + msg[1:] + "（没有参数）"
      action = msg[1:space]
      args = msg[space+1:]
      return "命令=" + action + "，参数=" + args

  print(parse_command("你好呀"))
  print(parse_command("/help"))
  print(parse_command("/give diamond"))
  ```
- 输出：
  ```
  这是普通聊天：你好呀
  命令：help（没有参数）
  命令=give，参数=diamond
  ```
- 截整屏。这张图串联了 if / 函数 / 字符串三课的知识，值得给读者看清楚。
