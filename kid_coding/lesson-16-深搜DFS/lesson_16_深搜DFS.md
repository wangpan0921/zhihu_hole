# 第 16 篇：自动寻路的史蒂夫：一格一格把每条路都试一遍

> 这是《我的世界里学编程》系列的第 16 篇,**第三阶段·算法关**的第 2 课。**上期回顾**:上一课我们请出了「自己叫自己」的**递归**,让史蒂夫在俄罗斯套娃式的洞穴里,先钻到最深处,再一层层原路撤回——DFS 的孪生兄弟就这么打了个照面。**今天**,洞穴里的路开始分岔了——史蒂夫脚下不再是一根直管,而是一张**方格迷宫**:每一步都能选**上/下/左/右**四个方向,还夹杂着**墙**和**死胡同**。手写「先试上、再试下……」的组合根本列不完。今天请出的新本领——**深搜 DFS(Depth-First Search,深度优先搜索)**——翻译成人话:**「一条路走到黑,走不通再退回来试另一条」**。它就是**递归 + 网格 + 回头**拧成的一根麻花。

## 先猜猜看

老规矩,先别急着往下拉。别怕代码有点长,粗看轮廓——**史蒂夫最后能不能找到出口?屏幕上会先打印哪一行?**

```python
maze = [
    ['S', '.', '#', '.'],
    ['#', '.', '.', '.'],
    ['#', '#', '#', 'E'],
]

ROWS = len(maze)
COLS = len(maze[0])
visited = [[False] * COLS for _ in range(ROWS)]

def dfs(r, c):
    if r < 0 or r >= ROWS or c < 0 or c >= COLS:   # 越界
        return False
    if maze[r][c] == '#':                           # 撞墙
        return False
    if visited[r][c]:                                # 走过了
        return False
    visited[r][c] = True
    print("走到", r, c)
    if maze[r][c] == 'E':
        print("找到出口!")
        return True
    if dfs(r - 1, c):    # 试:上
        return True
    if dfs(r + 1, c):    # 试:下
        return True
    if dfs(r, c - 1):    # 试:左
        return True
    if dfs(r, c + 1):    # 试:右
        return True
    return False

dfs(0, 0)
```

(提示:`dfs` 里居然又调用了 `dfs`——**上一课学过的「自己叫自己」在这里连叫了四次,一次试一个方向**。`S` 是起点,`E` 是出口,`#` 是墙,`.` 是能走的空地。)

猜好了记在心里,等下 I-do 一起对答案。

## 一句话接主线

史蒂夫举着火把,一头钻进了洞穴深处。可这次洞里不再是「一层套一层」的直管——**脚下多出一张方格地图,四面都有路,还夹着几堵石墙**。他犯了愁:「我该往哪走?会不会走到死胡同?会不会来回绕圈子?」我们凑过去说:**你不用一步想到出口——一条路走到黑,走不通就退回来,再换另一条**。这就是**深搜 DFS**——**信奥赛里探图、走迷宫、找路径,九成的入门题都靠它开局**。

## 从「一条走廊」讲起(I-do)

先想清楚**「深搜」的名字从哪儿来**——**「深」= 一头扎到底,「搜」= 挨个试一遍**。合起来就一句:**先沿着一条路一直往前走,走到没路了再退回来,换下一条继续**。

想象你手里握着一根线团(算法界的经典道具),走进一座迷宫。每进一格就在地上贴张便利贴写「来过」,然后**先挑一个方向死磕**;撞墙、出界、或撞上贴过便利贴的格子,就**顺着线原路退一格**,再挑另一个没试过的方向。**试遍所有方向都不行,就再往回退一格**。直到踩到出口——通关;或所有格子都试完还没找到——迷宫无解。

这套「进→退→换方向」的三步循环,写成代码简直就是**递归的原生态语言**。回到你刚才猜过的代码,我把关键点圈出来:

```python
def dfs(r, c):
    if r < 0 or r >= ROWS or c < 0 or c >= COLS:   # ①「不能走」的三道门:出界
        return False
    if maze[r][c] == '#':                           # ①「不能走」的三道门:撞墙
        return False
    if visited[r][c]:                                # ①「不能走」的三道门:走过了
        return False
    visited[r][c] = True                             # ②「贴便利贴」:标记来过
    print("走到", r, c)
    if maze[r][c] == 'E':                            # ③「到出口」:任务完成
        print("找到出口!")
        return True
    if dfs(r - 1, c):    # ④ 挨个试四个方向,一扇通了就够
        return True
    if dfs(r + 1, c):
        return True
    if dfs(r, c - 1):
        return True
    if dfs(r, c + 1):
        return True
    return False                                     # ⑤ 四个方向都不通,退给上一层
```

- **①「不能走」的三道门(越界 / 撞墙 / 已访问)**——**任何一道被挡,立刻掉头 return False**。翻译成人话:**「此路不通,别浪费下一步」**。
- **②「贴便利贴」(visited,已访问)**——**每到一个新格子就打个 ✓**。翻译成人话:**「走过的格子做个记号,免得转圈圈回来」**。这是本课**新增的一把刹车**——上一课的刹车是「底 base case」,这一课加上这把,**没有它,`dfs(0,1) → dfs(1,1) → dfs(0,1) → dfs(1,1) → ...` 就会来回横跳**,直接把 Python 叫爆(等下我们亲眼看一次)。
- **③「到出口」**——**任务完成,一路 return True 回去**。翻译成人话:**「找到啦,通知所有上层:大家撤!」**。
- **④「挨个试四个方向」**——**一次试一个;试到 True 就立刻沿着上层往回带信,剩下的不用敲**。翻译成人话:**「四扇门挨个敲,一扇通了就够」**。
- **⑤ 四个方向都不通**——**乖乖 return False**,让**上一层**换个方向继续试。这就是**回溯(backtrack)**——翻译成人话:**「走进死路就沿原路退一格」**——递归天生自带这个动作,不用你手写。

现在跑一下 `dfs(0, 0)`,输出:

```
走到 0 0
走到 0 1
走到 1 1
走到 1 2
走到 1 3
走到 0 3
走到 2 3
找到出口!
```

对照迷宫看一眼(记住 `(r, c)` 是**行号, 列号**,都从 0 数):

```
列号:    0    1    2    3
行 0:  [ S ][ . ][ # ][ . ]
行 1:  [ # ][ . ][ . ][ . ]
行 2:  [ # ][ # ][ # ][ E ]
```

顺着输出走一遍:从 (0,0) 起步 → 右走到 (0,1) → 下到 (1,1) → 右到 (1,2) → 右到 (1,3) → **上试了一下 (0,3)**——**这里就是一个死胡同**——(0,3) 的上/左/右全被挡,下面 (1,3) 又贴过便利贴,四道门全关,**乖乖退回 (1,3)**,再试**下** (2,3) → 撞上 `E`,**找到出口!**

看到 `走到 0 3` 后紧跟着 `走到 2 3` 了吗?**这就是 DFS 的灵魂**——**它真的走进了死胡同,乖乖退了一步,换个方向继续试**。这一「进一退」,就是**回溯**;这份「先深钻、再原路退」,就是上一课递归的「先进后出」在网格上的天然延伸。

## 一起改改看(We-do)

**实验 1:换个方向试试看**。把「上/下/左/右」的顺序改成「**右/下/左/上**」——就是让史蒂夫**先试右手边**——只改中间那 4 组:

```python
    if dfs(r, c + 1):    # 先试:右

    if dfs(r + 1, c):    # 再试:下

    if dfs(r, c - 1):    # 再试:左

    if dfs(r - 1, c):    # 最后试:上
```

**7 行**。比刚才**少了 1 行**——**少的正好是那趟死胡同 (0,3) 的一进一退**!因为这次史蒂夫**每一格都优先往右挪一步**,一路顺风顺水直接右→下→右→右→下,**根本没绕进那个死胡同**。你猜对了吗?

**翻译成人话**:**DFS 走出的路,取决于你让它「先试哪个方向」**——同一个迷宫,先试的方向不同,走过的格子就不一样。以后写题遇到「按什么顺序输出」的要求时,**方向的写法一个也不能错**。

**实验 2:故意把「贴便利贴」拿掉**。回到原版代码,把 `visited` 的读写(**`if visited[r][c]: return False` 那两行和 `visited[r][c] = True` 那一行,共三行**)整段删掉——就是**不再给走过的格子做记号**:

```python
def dfs(r, c):
    if r < 0 or r >= ROWS or c < 0 or c >= COLS:
        return False
    if maze[r][c] == '#':
        return False
    # ← visited 的三行整段删掉,别的一动不动
    print("走到", r, c)
    if maze[r][c] == 'E':
        print("找到出口!")
        return True
    if dfs(r - 1, c):
        return True
    if dfs(r + 1, c):
        return True
    if dfs(r, c - 1):
        return True
    if dfs(r, c + 1):
        return True
    return False

dfs(0, 0)
```

**先别运行**——猜一下:程序还能找到出口吗?

跑一下,你会看到屏幕**刷刷刷**打印一大串 `走到 0 1`、`走到 1 1`、`走到 0 1`、`走到 1 1`……**(0,1) 和 (1,1) 两个相邻格子在你眼前来回横跳**,最后 Python **自己报警**:

```
RecursionError: maximum recursion depth exceeded
```

翻译成人话:**「你叫太深了!」**——是不是**上一课的老朋友**?上一课是「忘写底 → 无限递归」,这一课是「忘贴便利贴 → 来回横跳,又变无限递归」。**DFS 的世界里,visited 就是新加的那把刹车,和 base case 一样,忘一个就翻车**。以后你写 DFS,请永远在心里念一遍这三件事:

- 底(什么时候停?撞墙/越界/到出口?)
- 便利贴(走过的格子做记号了吗?)
- 四个方向都试了吗?

## 今天你学会了

- **深搜 DFS(Depth-First Search,深度优先搜索)**——翻译成人话:**「一条路走到黑,走不通再退回来试另一条」**。它就是**上一课的递归**装上**方格地图 + 四个方向**跑起来的样子。
- **网格 = 二维列表**——翻译成人话:**列表里再套列表,像一张方格纸**。用 `(行号, 列号)` 定位每一格,两个都从 0 开始数。
- **DFS 的三道门**——每进一格先问:**出界了吗?撞墙了吗?走过了吗?**——任何一道被挡,立刻 `return False` 掉头。
- **visited(已访问)**——**这一课新增的第二把刹车**。翻译成人话:**「走过的格子做个记号,免得来回横跳」**。没有它,DFS 会在两个相邻格子之间死循环,又叫出 `RecursionError`——**上一课的那个报错今天又见面了**。
- **回溯(backtrack)**——翻译成人话:**「走进死路就沿原路退一格,再换个方向」**。**上一课递归的「先进后出」,在这里变成了「先深钻、后回退」——DFS 天生带自动回溯**。
- **方向的顺序会影响走出的路径**——**同一个迷宫,先试右和先试上,走过的格子并不一样**。写题时**方向别乱写**。

学到这里,你的程序第一次学会了**「自动寻路」**。**恭喜你,史蒂夫会走迷宫了**。

**🔴 进阶关**

现在把迷宫**换成一张更大的地图**,并且让 DFS **不仅走到出口,还要把走过的路径原样打印出来**(比如 `(0,0) → (0,1) → (1,1) → ...`):

```python
maze = [
    ['S', '.', '#', '.', '.'],
    ['#', '.', '.', '.', '#'],
    ['#', '#', '#', '.', '.'],
    ['.', '.', '.', '.', '.'],
    ['.', '#', '#', '#', 'E'],
]
```

- **提示 1**:开一个空列表 `path = []`。进入每一格时把 `(r, c)` **append 到 path**;**四个方向都试完还没找到时,把它 pop 掉**——**「进的时候写,退的时候擦」**——这正是回溯的经典写法。找到出口那一刻,把 `path` 打印出来就是完整路线。
- **提示 2**:别忘了 visited、别忘了越界和撞墙检查,DFS 的骨架和 I-do 完全一样,你只是多背了个「小本子」。
- **加分再一步**:把整张地图打印出来,把走过的格子换成 `*`,把出口保留成 `E`——一张史蒂夫亲手画的通关路线图就出来了。

## 下期预告

DFS 找到的是「一条通向出口的路」,但**它不一定是最短的那条**——它只挑「一条路先走到底」,能通就好,长短不管。可史蒂夫下次想**赶回家**,他要的是**最短路**——**不绕远、不走冤枉步**。**下一课**(第 17 篇)——**最短的回家路 · 广搜 BFS**,我们请出 DFS 的孪生兄弟**广搜(Breadth-First Search,广度优先搜索)**:**不再一条路钻到底,而是像水波纹一样一圈一圈地扩散出去**,第一次碰到出口的那一圈,就是最短距离。**同样是搜图,思路刚好反过来**——一个纵着钻、一个横着摊,两兄弟合起来,你就掌握了信奥赛「图论入门」的两把万能钥匙。
