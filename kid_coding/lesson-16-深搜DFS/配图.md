## 图2【概念图·加分】迷宫 = 二维列表(excalidraw)
- **插入位置**:「从『一条走廊』讲起」节,伪代码之前(讲「(r, c) = (行号, 列号)」时)
- 打开 https://excalidraw.com:
  - 顶部大标题:`迷宫 = 一张列表里再套列表`。
  - 左侧画 I-do 的 3×4 迷宫方格,尺寸约 400×300:
    - 行 0:`S`(浅绿), `.`(白), `#`(深灰), `.`(白)
    - 行 1:`#`, `.`, `.`, `.`
    - 行 2:`#`, `#`, `#`, `E`(金黄)
    - 每格左上角用小号字标 `(r, c)`,比如 `(0,0)`、`(0,1)`……`(2,3)`。
  - 右侧写对照的 Python 代码块:
    ```
    maze = [
      ['S', '.', '#', '.'],   # 行 0
      ['#', '.', '.', '.'],   # 行 1
      ['#', '#', '#', 'E'],   # 行 2
    ]
    ```
    用箭头把 `maze[0][3]` 连到网格里 (0,3) 那格。
  - 底部标注:**行号 r 从上往下、列号 c 从左往右,都从 0 数起**。
  - Sloppiness 选中间档(手绘亲切感)→ Export PNG,白底。

## 图3【概念图·必配】DFS 的三步循环:进 → 退 → 换方向(excalidraw)
- **插入位置**:「从『一条走廊』讲起」节,那段「进→退→换方向」文字之后、代码之前
- **这是本课的「灵魂图」**,画一个大三步循环:
  - 顶部大标题:`DFS 的三步循环 —— 一条路走到黑,走不通再退回来`。
  - 中间画一个大圆环,箭头顺时针,依次三个节点:
    - **① 进**(绿色):画一个史蒂夫小人向右迈一步进入新格子,格子里贴一张便利贴 ✓ (visited);下方注 `进入一格 → 贴便利贴`。
    - **② 试**(蓝色):画四个方向箭头 ↑↓←→,标注「挨个试」;下方注 `一次试一个方向,通了就走下去`。
    - **③ 退**(橙色):画一个「U 型掉头」箭头往回退,原格子上打个 ✗;下方注 `撞墙/出界/走过/四方向全试完 → return False,退给上一层`。
  - 圆环外围加三张「红牌」写「不能走」的三道门:`出界了? · 撞墙了? · 走过了?`——任何一张亮起,立刻回到 ③。
  - 底部大字口号:`一条路走到黑,走不通再退回来试另一条`。
  - 导出 PNG。
- **说明**:这张图今后凡是复习/串讲 DFS/BFS/回溯都可复用,是全系列长期资产。

## 图4【运行截图·必配】原版 DFS 完整输出

## 图6【运行截图·必配】We-do 实验 2:删掉 visited → RecursionError 翻车现场
- **插入位置**:「一起改改看」节,`跑一下,你会看到屏幕刷刷刷……` 那段话之后
- 粘贴**删掉 visited 三行**后的版本,尾部调 `dfs(0, 0)`,运行。屏幕会打印超长一串 `走到 0 1`、`走到 1 1`、`走到 0 1`、`走到 1 1`……最后停在:
  ```
  ...
  走到 0 1
  走到 1 1
  走到 0 1
  走到 1 1
  RecursionError: maximum recursion depth exceeded
  ```
- 截图重点:**红色报错信息 + 屏幕上被刷屏的 `走到 0 1 / 走到 1 1` 交替**——**视觉张力最强的一张**,一眼让读者对「忘写 visited = 翻车」留下条件反射。
- 用红笔在报错处画个大圈,旁边贴个 emoji 💥 表情,并在交替行左侧标注一个双向箭头:`(0,1) ⇄ (1,1) 来回横跳`。
- **可选**:在图旁边并排放上第 15 课的 `RecursionError` 截图,标题写「同一个报错,两种忘记」——**上一课忘写底,这一课忘贴便利贴**——把两把刹车的概念钉死。

## 图7【概念图·加分】回溯 = 进的时候写,退的时候擦(excalidraw)
- **插入位置**:「今天你学会了」节前,或在讲「回溯 backtrack」那句旁做小插图
- 画一条从起点到出口的方格路径,横向排 6 格:
  - 每格上方画一张便利贴 `(0,0) / (0,1) / (1,1) / (1,2) / (1,3) / (0,3)`。
  - 前 5 格便利贴颜色纯亮黄(在 path 列表里),第 6 格 `(0,3)` 涂灰色带一个 `✗ 死路,pop 掉` 的注释。
  - 每格下方对应写伪代码动作:`path.append((0,0))`、`path.append((0,1))`……到 `(0,3)` 写 `path.pop()  ← 退回来时擦掉`。
  - 顶部大标题:`回溯 = 进的时候写,退的时候擦`。
  - 底部口号条:`同一根便利贴本,进一格写一笔,退一步擦一笔——找到出口时,本子上留下的正好是完整通关路线`。
  - 导出 PNG。
- **说明**:这张图直接呼应 🔴 进阶关的「path 追加/pop」写法,可以留到讲进阶挑战时再看一次。
