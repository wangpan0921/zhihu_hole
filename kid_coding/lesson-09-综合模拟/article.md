## 今晚要打的这一仗

天彻底黑了。村口涌来一群僵尸，史蒂夫必须**独自守到天亮**——一个人，一把剑，脚下就是全部家当。

前 8 课学到的东西，今晚要**全部上阵**：

- 血量、攻击力得**记下来** → 第 1 课：变量

这种"照着规则老老实实模拟一遍"的题目，就叫**模拟题**。翻译成人话：**不用你想什么花招，把题目里的规则一条条翻成代码，就是标准解法。** 别小看它——CSP-J 里几乎每年都考，很多同学栽在"规则太多、写着写着乱了"。所以今天要练的**不是新语法**，是**把复杂问题切开、一小块一小块吃掉**的功夫。

## 第一步：把家底摆出来（I-do）

先把两边阵容摆好。史蒂夫的属性用**变量**（第 1 课），僵尸群用**列表套列表**（第 5 课）——每只僵尸是一小格 `[名字, 血量, 攻击力]`：

```python
# 史蒂夫的家底
steve_hp = 20
steve_atk = 5

# 僵尸群：每只是 [名字, 血量, 攻击力]
zombies = [
    ["普通僵尸A", 10, 2],
    ["普通僵尸B", 10, 2],
    ["强化僵尸",  18, 3],
    ["小僵尸",     5, 1],
]

# 天亮还需要几回合（回合制，别真等到早上 6 点）
night_turns = 6
```

翻译成人话：**每一个变量 / 每一格数据，都是从故事里"抠"出来的**。题目里说"血量 20"，代码里就写 `steve_hp = 20`；题目里说"僵尸有 3 项属性"，列表里就存 3 个数。**模拟题 90% 的力气，花在这一步：读题→翻译成数据。** 数据摆好，后面就顺了。

## 第二步：一个回合到底发生了什么（I-do）

先想清楚"一个回合"要做几件事——按顺序列出来：

1. 从**活着**的僵尸里，挑**血量最少**的作为攻击目标（第 5、8 课）
2. 史蒂夫砍它一刀，血量扣掉 `steve_atk`（第 1 课：`=` 是从右往左放进去）
3. 如果这只僵尸血量 ≤ 0，写一句"它倒下了"（第 2 课：if）
4. **所有还活着的**僵尸挨个咬史蒂夫一口，`steve_hp` 减去它们的攻击力（第 3 课：for）
5. 把这一回合发生的事写进日志（第 7 课：字符串）

看着挺乱？没关系——**把它打包成一个函数**（第 6 课），乱的部分就锁进机器里，外面只用它的名字：

```python
def by_hp(z):
    return z[1]     # 用血量当排序标准

def one_turn(hero_hp, hero_atk, zs, turn):
    log = []                                # 本回合日志（一串字符串）

    # (1) 挑活着的僵尸里血最少的
    alive = []
    for z in zs:
        if z[1] > 0:
            alive.append(z)
    if len(alive) == 0:
        return hero_hp, log                 # 没僵尸了，直接回去

    alive.sort(key=by_hp)
    target = alive[0]

    # (2) 史蒂夫砍一刀
    target[1] = target[1] - hero_atk
    log.append("回合" + str(turn) + "：史蒂夫劈了 " + target[0] + " " + str(hero_atk) + " 点")
    if target[1] <= 0:
        log.append("        " + target[0] + " 倒下了！")

    # (3) 活着的僵尸挨个反击
    for z in zs:
        if z[1] > 0:
            hero_hp = hero_hp - z[2]
            log.append("        " + z[0] + " 咬了史蒂夫 " + str(z[2]) + " 点")

    return hero_hp, log
```

翻译成人话，几个关键处：

- `alive = []` 加 `for + if + append`——**"过筛子"**的经典套路，第 5 课讲过：**把符合条件的元素挑出来，放进新列表**。
- `alive.sort(key=by_hp)` ——第 8 课的排序**终于派上真用场**：谁血少先打谁，收益最大（`by_hp` 就是"给僵尸打分的机器"）。
- `target[1] = target[1] - hero_atk` ——`target` 是 `alive[0]`。这里有个小玄机：`alive` 里存的**不是拷贝**，是**同一只僵尸的地址**，所以改 `target[1]` 也等于改 `zs` 里那只僵尸的血量。**你现在记住结论就行，第 22 课讲栈时会正式打开这个黑盒子。**
- 日志里全是**加号拼字符串**——第 7 课学过：**数字要先套 `str(...)` 才能拼**，不然会报"不能把数字加到字符串上"的错。
- 函数**返回了两样**：新的 `hero_hp` 和这回合的 `log`。写成 `return hero_hp, log`，外面用 `a, b = one_turn(...)` 一次性接住——这叫**多返回值**，翻译成人话就是"一台机器可以同时吐出好几件产品"。

## 第三步：主循环——什么时候停下来（I-do）

主循环的停止条件有**两个**：**史蒂夫死了**，或者**天亮 / 僵尸全灭**。任意一个成立，仗就打完。这天生适合 `while`（第 4 课）：

```python
def any_alive(zs):
    for z in zs:
        if z[1] > 0:
            return True
    return False

turn = 1
while steve_hp > 0 and any_alive(zombies) and turn <= night_turns:
    steve_hp, log = one_turn(steve_hp, steve_atk, zombies, turn)
    for line in log:
        print(line)
    print("        └─ 本回合结束，史蒂夫 HP =", steve_hp)
    print()
    turn = turn + 1

# 结算
if steve_hp <= 0:
    print("💀 史蒂夫倒下了……围城失败。")
elif not any_alive(zombies):
    print("🎉 僵尸全灭！史蒂夫剩 HP =", steve_hp)
else:
    print("🌅 天亮了！僵尸退散，史蒂夫剩 HP =", steve_hp)
```

翻译成人话：

- **`while 条件A and 条件B and 条件C:`** —— **三个条件必须全部成立**才继续下一回合，任何一个不成立立刻停。这是第 2 课布尔逻辑的直接应用。
- `any_alive` 也是一台"小机器"（函数）：进去一堆僵尸，出来 `True` / `False`。**遇到一只活的就直接 `return True`**——这种"早发现早撤退"的写法叫**提前返回**，翻译成人话就是"办完事立刻走人，别磨蹭"。比先算完再判断快得多。
- 结算用 `if / elif / else`（第 2 课）——**三种结局**只会走进一种。

## 完整代码 + 运行结果（I-do 收尾）

把上面三段接起来，就是一份**能跑**的僵尸围城模拟：

```python
# ---- 数据（第 1、5 课）----
steve_hp = 20
steve_atk = 5

zombies = [
    ["普通僵尸A", 10, 2],
    ["普通僵尸B", 10, 2],
    ["强化僵尸",  18, 3],
    ["小僵尸",     5, 1],
]

night_turns = 6

# ---- 工具函数（第 6 课）----
def by_hp(z):
    return z[1]

def any_alive(zs):
    for z in zs:
        if z[1] > 0:
            return True
    return False

def one_turn(hero_hp, hero_atk, zs, turn):
    log = []
    alive = []
    for z in zs:
        if z[1] > 0:
            alive.append(z)
    if len(alive) == 0:
        return hero_hp, log
    alive.sort(key=by_hp)
    target = alive[0]

    target[1] = target[1] - hero_atk
    log.append("回合" + str(turn) + "：史蒂夫劈了 " + target[0] + " " + str(hero_atk) + " 点")
    if target[1] <= 0:
        log.append("        " + target[0] + " 倒下了！")

    for z in zs:
        if z[1] > 0:
            hero_hp = hero_hp - z[2]
            log.append("        " + z[0] + " 咬了史蒂夫 " + str(z[2]) + " 点")

    return hero_hp, log

# ---- 主循环（第 4 课）----
turn = 1
while steve_hp > 0 and any_alive(zombies) and turn <= night_turns:
    steve_hp, log = one_turn(steve_hp, steve_atk, zombies, turn)
    for line in log:
        print(line)
    print("        └─ 本回合结束，史蒂夫 HP =", steve_hp)
    print()
    turn = turn + 1

# ---- 结算（第 2 课）----
if steve_hp <= 0:
    print("💀 史蒂夫倒下了……围城失败。")
elif not any_alive(zombies):
    print("🎉 僵尸全灭！史蒂夫剩 HP =", steve_hp)
else:
    print("🌅 天亮了！僵尸退散，史蒂夫剩 HP =", steve_hp)
```

改完之后回头想一件事——**你的每次修改，其实只碰了整份代码里"很小的一块"**：改攻击力只动了数据；改策略只动了 `key=` 的方向；加 BOSS 只动了列表；加喝血只动了一个函数。这就是**把复杂问题切成小块**的好处——**局部改动，不动全身**。以后代码越写越长，这个功夫越管用。

## 今天你学会了

- **模拟题的三步套路**：① 读题→数据；② 把"一个回合 / 一步"打包成函数；③ 主循环控制"什么时候停"。
- **变量 + 列表套列表**：一队僵尸就是 `[[名字, 血, 攻击], ...]`——`zombies[i][j]` 定位到"第 i 只的第 j 项"。
- **`for + if + append` 过筛子**：从一堆里挑出满足条件的一小撮，是**列表操作最常用**的套路。
- **`sort(key=函数)` 挑目标**：排序不只是"整理"，更是"**替决策服务**"——先打血最少的？血最厚的？换个 `key` 就是换个策略。
- **`while 条件A and 条件B and 条件C:`**：多条件同时成立才继续，任何一个变假就退出——布尔逻辑与循环的组合拳。
- **函数返回多个值**：`return a, b` + `x, y = 函数()`，一次带回一批结果。
- **数字拼字符串要 `str(...)`**：写日志、拼消息时最常见的坑。
- **提前返回**：`for + if: return True` / 最后 `return False`——一遇到就撤，比循环完再判断快。

**一句话总结**：模拟题不是"想不到"，是**"没耐心把每一步分清楚"**。今天这份代码把前 8 课**每一课都点了名**——如果你能把它从头默着敲一遍、还改出前 4 个变体，那**第一阶段你已经稳了**。

## 课后挑战

**🟢 基础关**

在完整代码基础上做三件事：

1. 每回合结束时**多打印一行**"当前还有 X 只僵尸活着"（提示：写一个 `count_alive(zs)` 函数，思路和 `any_alive` 类似，但用**计数变量**代替 `return`）。
2. 战斗结束后打印一行"共打了 X 回合"（`turn - 1` 是打过的回合数——想想为什么减 1）。
3. 把 `["强化僵尸", 18, 3]` 的攻击力从 3 改成 4，重新跑一遍——是不是感觉"就改一个数"就能测无数种平衡？——**这就是模拟的价值**。

**🔴 进阶关**

给史蒂夫加**一把新武器**——用**列表**存：`sword = ["铁剑", 5, 15]`，三项分别是 `[名字, 攻击力, 耐久]`。规则：

- 史蒂夫每砍一刀，`sword[2]` 减 1。
- 当 `sword[2] <= 0`，剑断了：**从这一回合起攻击力掉回 1**（拳头），日志里输出 `"⚠️ 铁剑断了！史蒂夫改用拳头。"`
- 攻击力从"变量 `steve_atk`"改成"跟着剑走"——每回合开始时根据剑的耐久决定用几点攻击。

> 小提示：不用把 `one_turn` 大改，只需要把**攻击力从哪儿来**这一点动一下。信奥赛判卷不看你改了几行——**看你有没有把规则老老实实翻译对**。

**加分挑战**：让僵尸也带一个"愤怒值"——每被砍一刀，它下一次的攻击力 +1（凶狠反扑）。写完你会发现，**列表套列表的第 4 号位置**（`z[3]`）就够记这件事——这就是模拟题**逐步加规则**的正确姿势。
