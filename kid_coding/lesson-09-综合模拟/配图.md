# 第9课《综合模拟：僵尸围城》配图制作方法

> 全 8 张图。分工：插画用 AI 提示词；概念图用 excalidraw 逐元素脚本；代码运行图用真实截图。
> 优先级：时间紧只做 3 张必配 —— 图1 封面、图3 模拟题三步套路、图6 完整对战日志截图。

## 图1【封面·必配】AI 提示词
- **插入位置**：文章顶部封面
- **中文提示词（即梦/通义万相/文心一格）**：
  > 像素风格插画，夜色笼罩的《我的世界》风格村庄，村口一个方块像素风格的男孩角色手持发光铁剑，独自面对一群方块像素僵尸从远处扑来。男孩头顶悬浮着一个半透明的 UI 面板，上面显示 "HP 20" 的红色血条和 "回合 1" 的计数器。天空是深蓝紫色，月亮圆而明亮，地面撒着细小的火把光。整体气氛紧张但带点搞笑，卡通可爱风格，适合儿童教育。画面上下留出空白区域用于放置标题文字。16:9横版构图。
- **英文提示词（Midjourney/SD/DALL·E）**：
  > pixel art illustration, nighttime Minecraft-style village, a blocky voxel boy standing alone at the village entrance holding a glowing iron sword, facing a horde of blocky voxel zombies rushing from the distance. - **注意**：AI 常把 UI 面板画得像真的游戏截图。让它画成手绘悬浮标牌感、明显区别于官方 UI，规避素材侵权。

## 图2【概念图·加分】把大问题切成小块（excalidraw）
- **插入位置**：「今晚要打的这一仗」节末尾，讲"模拟题"定义处
- 打开 https://excalidraw.com：
  - 顶部标题：`模拟题 = 把一大坨规则切成一小块一小块`。
  - 左侧画一个大灰色云朵，里面塞满乱糟糟的文字："血量20、攻击力5、4只僵尸、每只属性不同、先打谁？、谁死了？、打到天亮或死为止…"，云朵旁边一个头顶发懵冒问号的小人。
  - 中间画一个大的粗箭头，箭头上写「切！」。
  - 右侧竖排 3 个整齐的方块卡片：
    - 卡片1（浅蓝）：`① 读题→数据`（图标：一个便签+一个箱子）
    - 卡片2（浅黄）：`② 把"一步"打包成函数`（图标：齿轮机器）
    - 卡片3（浅绿）：`③ 主循环控制"何时停"`（图标：循环箭头+红叉）
  - Sloppiness 中间档 → Export PNG，白底。

## 图3【概念图·必配】前 8 课如何被"点名"（excalidraw）
- **插入位置**：「今晚要打的这一仗」节前 8 课清单之后
- 顶部标题：`一场僵尸围城，8 课全上阵`
- 中间画一个大圆（今晚的战斗），外围 8 个小圆环绕，每个小圆代表一课，用箭头指向中心，标注它在战斗里的角色：
  - L1 变量 → 记 hp / atk
  - L2 条件 → 判断死没死、天亮没
  - L3 for → 遍历僵尸列表
  - L4 while → 主循环"打到天亮或阵亡"
  - L5 列表 → 装一队僵尸（列表套列表）
  - L6 函数 → `one_turn` 打包一个回合
  - L7 字符串 → 拼战斗日志
  - L8 排序 → 挑血最少的先打
- 中心大圆内写：`回合制僵尸围城战`。
- 每个小圆用不同颜色，箭头统一深灰。
- 导出 PNG。**这张是全篇的"合影"，最有仪式感，读者一眼看到"我真的学过这么多东西"。**

## 图4【概念图·加分】一个回合的流水线（excalidraw）
- **插入位置**：「第二步：一个回合到底发生了什么」节末尾
- 顶部标题：`one_turn(hero_hp, hero_atk, zs, turn) —— 一个回合流水线`
- 从左到右 5 个步骤方框，用箭头连接：
  - `① 过筛子` alive = 活着的僵尸（图标：漏斗）
  - `② 排序` alive.sort(key=by_hp)（图标：从低到高的柱状图）
  - `③ 砍一刀` target[1] -= atk（图标：铁剑）
  - `④ 判定` target 死没死？（图标：问号+骷髅头）
  - `⑤ 反击` 活着的僵尸挨个咬（图标：僵尸牙齿）
- 流水线上方用虚线气泡标注每一步用到的知识点：`第 5 课 / 第 8 课 / 第 1 课 / 第 2 课 / 第 3 课`。
- 底部输出两个东西：`hero_hp（新血量）` 和 `log（本回合日志）`——箭头指向外部一个"信封"（表示 return 出去）。
- 导出 PNG。

## 图5【概念图·加分】while 三条件同时成立（excalidraw）
- **插入位置**：「第三步：主循环」节末尾
- 顶部标题：`while A and B and C: —— 三根柱子撑一天`
- 画一个古罗马神庙风格的三柱结构，屋顶写 `继续下一回合`：
  - 柱 1：`steve_hp > 0`（图标：红心血条）
  - 柱 2：`any_alive(zombies)`（图标：一群僵尸）
  - 柱 3：`turn <= night_turns`（图标：日历/沙漏）
- 三根柱子下方各写「成立 ✓」；
- 旁边画一个小神庙倒塌的版本：任意一根柱子变成灰色带叉，屋顶塌下来 → 底部三种结局：
  - 柱 1 塌：`💀 史蒂夫倒下`
  - 柱 2 塌：`🎉 僵尸全灭`
  - 柱 3 塌：`🌅 天亮`
- 底部注：`任何一根塌了，主循环立刻停。这就是布尔"与"的意思。`
- 导出 PNG。

## 图6【运行截图·必配】完整对战日志
- **插入位置**：「完整代码 + 运行结果」节
- 打开 https://www.online-python.com，粘贴文章里"完整代码"整段代码，运行，截**代码 + 输出**整屏。
- 输出关键行（截图里必须清晰可见）：
  ```
  回合1：史蒂夫劈了 小僵尸 5 点
          小僵尸 倒下了！
          普通僵尸A 咬了史蒂夫 2 点
          ...
          └─ 本回合结束，史蒂夫 HP = 13
  ...
  💀 史蒂夫倒下了……围城失败。
  ```
- 字号调大，配色和全系列保持一致。这张图是本篇的"高光时刻"——**前 8 课的知识第一次一起产出一段像回放录像的输出**。

## 图7【运行截图·加分】We-do 改动 1 前后对比
- **插入位置**：「一起改改看」节末尾（可选，作为改完的验证）
- 同一份代码，只把 `steve_atk = 5` 改成 `steve_atk = 7`。两次运行截图上下拼贴：
  - 左/上：atk=5 → 失败结局（`💀 史蒂夫倒下`）
  - 右/下：atk=7 → 胜利结局（`🎉 僵尸全灭 / 🌅 天亮`）
- 在两张截图之间加一行大字标注 `就改一个数字，故事完全不同！`——直观展示"模拟题 = 参数调优器"。

## 图8【总结卡·加分】今天你学会了（Canva/创客贴，套用系列模板）
- **插入位置**：「今天你学会了」节
- 竖版 3:4 卡片，沿用第 1 课起的固定版式（只改课号与内容）：
  - 顶部：`第 9 课 · 知识清单` +《我的世界里学编程》
  - 6 条要点（每条配 emoji）：
    - 🎯 模拟题三步：数据 → 一步打包 → 主循环停
    - 🧱 列表套列表 —— `bag[i][j]` 存"第 i 件的第 j 项"
    - 🥅 `for + if + append` —— 过筛子挑元素
    - 🔀 `sort(key=)` —— 排序为决策服务
    - 🚦 `while A and B and C:` —— 多条件同时成立才继续
    - 📦 `return a, b` —— 函数一次吐两件产品
  - 底部：品牌栏 + 公众号名。
- **这张卡是"第一阶段收官卡"**，可以在右上角加一个小徽章 `第一阶段·完`，庆祝仪式感拉满。

## 版权红线
- 封面/预告图/UI 面板**不要直接用《我的世界》官方截图或美术资源**做付费号主视觉，请用像素风自制或 AI 生成的"致敬风格"规避风险。
- 战斗日志里的物品与生物名称（僵尸、苦力怕、铁剑、钻石等）属于游戏机制的合理引用，风险低。
- 数值配平（HP / 攻击力 / 回合数）**避免直接照搬《我的世界》官方数值**，本篇采用便于教学的整齐小数字（20/5/2/3），既降低阅读负担也回避争议。
- 生成图里避免出现明显的《我的世界》官方 logo、字体、标志性 UI（如 F3 调试信息、成就弹窗）——保持"像素风教育插画"的气质。
