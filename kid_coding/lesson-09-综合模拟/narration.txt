### 16 | 第三步：主循环——什么时候停下来（I-do）（续）
翻译成人话：
while 条件A and 条件B and 条件C: —— 三个条件
必须全部成立才继续下一回合，
任何一个不成立立刻停。
这是第 2 课布尔逻辑的直接应用。
any_alive 也是一台"小机器"（函数）：
进去一堆僵尸，出来 True / False。
遇到一只活的就直接 return True，
这种"早发现早撤退"的写法叫提前返回，
翻译成人话就是"办完事立刻走人，别磨蹭"。
比先算完再判断快得多。
结算用 if / elif / else（第 2 课）——三种结局只
会走进一种。

### 27 | 今天你学会了
模拟题的三步套路：
① 读题→数据；
② 把"一个回合 / 一步"打包成函数；
③ 主循环控制"什么时候停"。
变量 + 列表套列表：
一队僵尸就是 [[名字, 血, 攻击], ...]——zombies
[i][j] 定位到"第 i 只的第 j 项"。
for + if + append 就是过筛子：
从一堆里挑出满足条件的一小撮，是列表操作最常用的套路。
sort(key=函数) 挑目标：
排序不只是"整理"，更是"替决策服务"
——先打血最少的？还是血最厚的？
换个 key 就是换个策略。
while 条件A and 条件B and 条件C:：
多条件同时成立才继续，
任何一个变假就退出——布尔逻辑与循环的组合拳。
函数返回多个值：
return a, b + x, y = 函数()，
一次带回一批结果。
数字拼字符串要 str(...)：
写日志、拼消息时最常见的坑。

### 28 | 今天你学会了（续）
提前返回：
for + if: return True / 最后 return
False
——一遇到就撤，比循环完再判断快。

模拟题不是"想不到"，是"没耐心把每一步分清楚"。

——如果你能把它从头默着敲一遍、还改出前 4 个变体，
那第一阶段你已经稳了。
