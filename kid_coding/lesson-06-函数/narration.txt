### 6 | 造一台你自己的合成台（I-do）
在 Python 里，造一台合成机器只要三行。
拆开来看，def 的意思是：「我要造一台机器！」
后面跟机器的名字 make_sword，也就是造剑。
material 是这台机器的投料口。
每次使用，都要塞一份材料进来。
material 是材料的临时名字，只在机器内部有效。
这个投料口，程序员管它叫参数，也就是 parameter。
翻译成人话，就是「机器留给你塞东西的洞」。

### 7 | 造一台你自己的合成台（I-do）（续）
return material 加上「剑」，表示机器加工完了。
接着，它从出料口吐出成品。
这一步叫返回，也就是 return。
翻译成人话，就是「把成品交回给调用我的人」。
def 那行结尾有冒号，内部代码要缩进四个空格。
Python 用缩进判断哪些代码属于机器内部。
就像用篱笆把车间围起来。
造好之后怎么用？
直接叫它的名字，把材料塞进去。

### 14 | return vs print：吐成品，还是自言自语？（续）
看看输出，你看懂了吗？
print 只是让机器当场喊一嗓子，喊完什么都没端出来。
所以变量 a 接了个空气，Python 把它记作 None。
翻译成人话，就是「啥也没有」。
return 才会把成品交给你。
你可以用变量接住、继续拼装，再喂给下一台机器。

### 15 | return vs print：吐成品，还是自言自语？（续）

### 19 | 今天你学会了
今天我们学会了，函数就是自己造的机器。
用 def、函数名和参数开头，缩进写内部套路。
参数就是投料口，可以有零个、一个或多个。
return 会把成品交给外面继续使用。
print 只是喊一嗓子，不会交出成品。
写函数名、括号和投料，就是调用函数。
多个参数会按位置对号入座，顺序不能错。
少喂或多喂参数，都会触发 TypeError。
有了函数，史蒂夫不用再重敲同一段代码。
这也是以后学习编程和信息学奥赛的重要地基。
