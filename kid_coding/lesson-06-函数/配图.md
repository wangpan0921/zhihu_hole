## 图2【概念图·加分】函数 = 一台机器（excalidraw）
- **插入位置**：「造一台你自己的合成台（I-do）」节开头，`def make_sword(material):` 之前
- 打开 https://excalidraw.com：
  - 中间画一个大矩形机器（约 400×250），里面写 `make_sword`（函数名），机器风格：外框深灰、内部浅灰、四角有小铆钉圆。
  - 机器**左侧**画一个漏斗形状的投料口，上方一个小方块 `"铁"` 正落进去；漏斗下方写标签 `参数 material`。
  - 机器**右侧**画一个开口，一把「铁剑」方块正从里面弹出；下方写标签 `返回值 铁剑`。
  - 机器内部小字：`return material + "剑"`。
  - 顶部标题：`函数 = 你自己造的机器`。
  - 底部小字：`投料 → 加工 → 出料，套路只写一次，永远备用。`
  - Sloppiness 选中间档（手绘感）→ Export PNG，白底。

## 图3【概念图·必配】def 语法拆解（excalidraw）
- **插入位置**：「造一台你自己的合成台（I-do）」节，讲拆解 `def make_sword(material):` 处
- 画一行大字号代码 `def make_sword(material):`（等宽字体、字号 40+），然后从每个部分**拉出彩色气泡箭头**指向下方对应说明：
  - `def` →（蓝色气泡）「我要造一台机器！」
  - `make_sword` →（紫色气泡）「机器的名字」
  - `(material)` →（橙色气泡）「投料口 = 参数」
  - `:` →（灰色气泡）「冒号：下面是机器内部」
- 冒号下方画第二行代码 `    return material + "剑"`（保留 4 空格缩进），从 `return` 拉出（绿色气泡）「把成品端出去！」；从 4 空格缩进拉出（红色气泡）「缩进 = 篱笆，圈出机器内部」。
- 顶部标题：`拆开看这一行：一台机器怎么造出来？`
- Export PNG，白底。

## 图4【运行截图·加分】三次调用同一台机器
- **插入位置**：「造一台你自己的合成台（I-do）」节末尾，`木剑 / 铁剑 / 钻石剑` 输出处
- 用在线编辑器（https://www.online-python.com 或 https://pythontutor.com），粘贴：
  ```python
  def make_sword(material):
      return material + "剑"

  print(make_sword("木"))
  print(make_sword("铁"))
  print(make_sword("钻石"))
  ```
- 运行输出正好三行 `木剑 / 铁剑 / 钻石剑`，截「代码 + 输出」整屏。字号调大，保持与前五课同一编辑器与配色。
- 也可用 `./venv/bin/python scripts/kid_coding_images.py --lesson 6` 自动生成本课所有代码/终端图。
- 加分做法：再截一张 pythontutor 单步图，展示三次调用时 `material` 每次分别变成什么——一层层小房间看得清清楚楚。

## 图5【运行截图·必配】return vs print 对比
- **插入位置**：「return vs print：吐成品，还是自言自语？」节末尾
- 粘贴并运行：
  ```python
  def craft_A(material):
      print(material + "剑")

  def craft_B(material):
      return material + "剑"

  a = craft_A("铁")
  b = craft_B("铁")

  print("a 拿到了：", a)
  print("b 拿到了：", b)
  ```
- 截整屏，重点保留输出的三行：
  ```
  铁剑
  a 拿到了： None
  b 拿到了： 铁剑
  ```
- 用红框圈住 `a 拿到了： None`，右侧手写小气泡：`print 只是喊一嗓子，什么也没端出来！`
- 加分做法：在截图上把 `print` 那台机器画成一个开口向上、烟消散的漏斗；把 `return` 那台画成一个端出成品盘子的机器手臂。**这张越戏剧化越好记**。

## 图6【概念图·加分】参数按位置对号入座（excalidraw）
- **插入位置**：「多个投料口：合成表也能背下来」节 或「一起改改看（We-do）」的顺序换位处
- 画法：
  - 上半部分：画一台机器 `make_potion`，两个投料口从左到右标 `main / extra`。左侧代码 `make_potion("苦力怕的眼泪", "糖")`，从两个字符串分别拉箭头，**平行**指向 `main / extra`。右侧出料口吐出 `药水（苦力怕的眼泪 + 糖）`。
  - 下半部分：同一台机器。左侧代码换成 `make_potion("糖", "苦力怕的眼泪")`，两条箭头**交叉**指向 `main / extra`（画成 X 形以强调换了位）。右侧出料口吐出 `药水（糖 + 苦力怕的眼泪）`。
  - 顶部标题：`参数按位置对号入座 —— 顺序一换，成品就变`。
  - 底部小字：`第一个投料口 ← 第一份材料；第二个投料口 ← 第二份材料。喂错了机器不会报错，只会给你错的成品——最坑的一种 bug。`
- Export PNG，白底。

## 图7【总结卡·加分】今天你学会了（Canva/创客贴）
- **插入位置**：「今天你学会了」节
- 沿用系列固定竖版模板（3:4），编号改「第 6 课」，7 条要点：
  - 🏭 函数 = 自己造的机器（`def 名字(投料口):`）
  - 🎯 参数：投料口，可以有 0 / 1 / N 个
  - 📦 return：把成品端出去
  - 📢 print ≠ return：喊一嗓子 ≠ 端出成品
  - 🔘 调用：`函数名(材料)` = 按下开关
  - ➡️ 参数按位置对号入座，顺序别错
  - ⚠️ `TypeError` = 投料数量对不上
- 每条配 emoji/小图标，用系列主色。底部品牌栏 + 公众号名，与前五课模板保持一致。
