# 第 5 篇：背包格子怎么管理？——认识列表

> 这是《我的世界里学编程》系列的第 5 篇。**上期回顾**：上一课我们学会了 while 循环，让史蒂夫熬过了漫漫长夜。今天清晨，他打开背包一看——里面**乱成了一锅粥**：钻石压着面包，铁剑埋在苹果堆里。这一课，我们要教他把背包整整齐齐排开，随时能查、能加、能扔。这就是程序员天天在用的——**列表（list）**。目标依旧是通向信息学奥赛，但今天只攻一个点：列表。

## 先猜猜看

老规矩，别急着往下看。心里先跑一遍，这段代码会打印出什么？

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]

print(bag[0])
print(bag[2])
```

（提示：一共只有两行输出。悄悄告诉你一个坑——**下标从 0 开始数**。）

猜好了吗？我们待会儿揭晓。

## 史蒂夫的新麻烦

熬过第一夜的史蒂夫，白天出门溜达一圈，回家一清点战利品：

- 3 块钻石
- 2 个金锭
- 5 个面包
- 1 把铁剑
- 若干苹果……

他想说：「电脑，帮我记一下我今天带回来的东西。」

用之前学的**变量**行不行？

```python
item1 = "钻石"
item2 = "金锭"
item3 = "面包"
item4 = "铁剑"
item5 = "苹果"
```

……这也太蠢了。要是明天他带回来 30 样东西呢？难道 `item1` 一直写到 `item30`？

这时候就该轮到今天的主角上场了：**列表**。

翻译成人话：**列表就是一排格子，一个格子放一样东西，从左往右按顺序排队，谁也不许插队。**

故事线接一下：学会列表之后，史蒂夫从「东西一多就抓瞎」进化成了「背包管理员」。以后不管他捡回来多少战利品，一个变量就能全装下——这也是所有《我的世界》玩家背包栏、《原神》圣遗物界面、甚至你手机相册背后的同一个东西。

## 列表长什么样

写一个列表非常简单：**方括号 `[]`，中间用逗号隔开**。

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]
```

翻译成人话：**「造一个叫 bag 的排格子，从左到右依次塞进这 5 样东西。」**

想拿其中某一格的东西，就用**中括号加下标**——比如 `bag[0]` 就是第一格：

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]

print(bag[0])
print(bag[2])
```

输出：

```
钻石
面包
```

回到开头那道猜题——是不是打印了 `钻石` 和 `面包`？

等等，`bag[2]` 明明是**第 3 个**位置，为啥叫 `[2]`？

## 下标从 0 开始：程序员的怪癖

这是新手最容易懵的一件事：**列表的第一个位置叫 `[0]`，不叫 `[1]`**。

```
bag  =  [ "钻石" , "金锭" , "面包" , "铁剑" , "苹果" ]
下标：      0        1        2        3        4
```

数一数你就明白了：`bag[0]` 是钻石，`bag[2]` 是面包，`bag[4]` 是苹果。

为啥非要从 0 开始？简单说——**下标其实不是「第几个」，而是「跨几步」**。第一格就在开头，跨 0 步；第二格得跨 1 步……程序员觉得这样算最省事，就干脆全世界统一了。

翻译成人话：**下标不是「第几个」，是「从头跳几步」。跳 0 步就在原地，所以 `[0]` 是第一格。**

顺便试一个小机灵鬼玩法——写 `-1` 会怎样？

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]
print(bag[-1])
```

输出：

```
苹果
```

`-1` 表示**从右往左数第一个**，也就是最后一格。以后想拿「刚捡到的那个」，`bag[-1]` 一步到位。

## 一起改改看（We-do）

轮到你动手。把下面这行代码里的下标 `2` 改成 `5`，看看会发生什么：

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]
print(bag[5])
```

**先预测**：这段会打印什么？

> 揭晓：程序会**报错**！错误信息大概长这样：
>
> ```
> IndexError: list index out of range
> ```
>
> 翻译成人话：**「你要的那格根本不存在。」** 背包一共 5 格，编号只到 `[4]`，你伸手去掏 `[5]`——掏了个空气。
>
> 这个坑叫**「下标越界」**，是新手写列表最常踩的雷，没有之一。以后每次用 `bag[某个数]` 前，先在心里问一句：「这个数会不会超过背包最后一格的编号？」

再试一次：把 `5` 改成 `-1`——是不是就变成 `苹果` 了？负数下标不会越界（只要不越到左边太远），因为它是从右往左数的。

## 遍历：一次看遍所有格子

要挨个查看背包里每一样东西，难道要写 5 行 `print(bag[0])`、`print(bag[1])`……吗？当然不用。用上一课学过的 for 循环，一句话搞定：

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]

for item in bag:
    print("发现：", item)
```

输出：

```
发现： 钻石
发现： 金锭
发现： 面包
发现： 铁剑
发现： 苹果
```

翻译成人话：**「让 item 依次代表 bag 里的每一样东西，每替换一次就跑一遍缩进里的活。」**

这种「把一个列表里的每一样都过一遍」的操作，程序员叫它——**遍历**。以后你会在无数地方见到它：一次结算 30 只怪的伤害、一次给 100 个玩家发奖、一次刷新整张地图的方块——底下全是这三个字。

想同时知道**下标和内容**？用 `enumerate`（多了个「编号器」）：

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]

for i, item in enumerate(bag):
    print("第", i, "格是：", item)
```

输出：

```
第 0 格是： 钻石
第 1 格是： 金锭
第 2 格是： 面包
第 3 格是： 铁剑
第 4 格是： 苹果
```

## 加一样、扔一样

背包不是死的，能加能减。

**捡到东西 → 塞进背包最后一格**，用 `.append()`：

```python
bag = ["钻石", "金锭", "面包", "铁剑"]
bag.append("苹果")
print(bag)
```

输出：

```
['钻石', '金锭', '面包', '铁剑', '苹果']
```

翻译成人话：**append 就是「往队尾追加一个」**。

**扔掉一样东西**，用 `.remove()`：

```python
bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]
bag.remove("金锭")
print(bag)
```

输出：

```
['钻石', '面包', '铁剑', '苹果']
```

翻译成人话：**remove 就是「按名字扔掉一个」**——注意，只扔**第一个**匹配的，后面重名的不管。

顺便认识两个万能工具：

- `len(bag)`——**这个背包一共几格？**（4 就是 4，别再脑补 5。）
- `bag[0] = "绿宝石"`——**把第 0 格直接换成绿宝石**（原来的钻石就没了）。

## 今天你学会了

- **列表 `[]`**：一排格子，从左到右按顺序放东西
- **下标从 0 开始**：`bag[0]` 是第一格；`bag[-1]` 是最后一格
- **越界会报错**：伸手去掏不存在的格子 → `IndexError`
- **遍历 `for x in bag`**：一句话过完每一格
- **`enumerate`**：想同时拿到下标和内容时用
- **增删改查**：`append` 加、`remove` 扔、`bag[i] = 新值` 换、`bag[i]` 查
- **`len(bag)`**：告诉你背包里现在有几样

有了列表，史蒂夫从「东西一多就抓瞎」升级成了「背包管理员」。从这一课开始，你写的每一段程序，几乎都会带着一个甚至好几个列表——它就是这么常用。
