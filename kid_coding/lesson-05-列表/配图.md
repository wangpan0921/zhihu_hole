## 图2【概念图·加分】变量 vs 列表 对比（excalidraw）
- **插入位置**：「史蒂夫的新麻烦」讲到「一直写 `item1` 到 `item30` 太蠢」的地方
- 打开 https://excalidraw.com：
  - 左半：画 5 个**互相分离**的小箱子，每个箱子上贴便利贴 `item1`…`item5`，箱子上方写 `item1 = "钻石"` 等等 5 行代码，标题「一个变量装一样」→ 红叉「东西一多就抓瞎」。灰色系。
  - 右半：画一个**横向连成一排**的大格子（5 格拼在一起），格子上方是一张大便利贴写 `bag`，格子下方标编号 0-4，标题「一个列表装一整排」→ 绿色对勾。绿色系。
  - 中间竖虚线分隔；顶部标题：`5 个变量 vs 1 个列表：谁更省事？`
  - Sloppiness 选中间档（手绘感）→ Export PNG，白底。

## 图3【概念图·必配】下标从 0 开始（excalidraw）
- **插入位置**：「下标从 0 开始：程序员的怪癖」节
- 画一排 5 个格子（横向拼接）：
  - 每格上方写内容：钻石 / 金锭 / 面包 / 铁剑 / 苹果。
  - 每格下方写下标：0 / 1 / 2 / 3 / 4（红色大字，突出）。
  - 最左边格子外画一个「起点」小旗子，从起点往每格画一条带数字的箭头：跨 0 步 / 跨 1 步 / 跨 2 步 / 跨 3 步 / 跨 4 步。
  - 顶部标题：`下标 = 从头跳几步（不是"第几个"）`
  - 底部小字：`跳 0 步就在原地 → 所以第一格叫 [0]`
  - 右侧加一个补充小方框：`bag[-1] = "苹果"（从右数第一个）` 附反方向箭头。
- Export PNG，白底。

## 图4【运行截图·加分】第一段猜题运行结果
- **插入位置**：「列表长什么样」节末尾
- 用在线编辑器（https://www.online-python.com 或 https://pythontutor.com），粘贴：
  ```python
  bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]

  print(bag[0])
  print(bag[2])
  ```
- 运行输出正好两行 `钻石` / `面包`，截「代码 + 输出」整屏。字号调大，保持与前四课同一编辑器与配色。
- 也可用 `./venv/bin/python scripts/kid_coding_images.py --lesson 5` 自动生成本课所有代码/终端图。

## 图5【运行截图·必配】越界报错截图
- **插入位置**：「一起改改看（We-do）」揭晓答案处
- 粘贴并运行：
  ```python
  bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]
  print(bag[5])
  ```
- 截整屏，重点保留错误信息 `IndexError: list index out of range`。红色高亮框圈住这一行。
- 加分做法：右下角贴一个「小恶魔」emoji + 文字气泡：`背包只有 [0]-[4]，你伸手掏 [5] 掏了个空气！`。这张越"戏剧化"越好记。

## 图6【运行截图·加分】遍历 + enumerate
- **插入位置**：「遍历：一次看遍所有格子」节
- 运行并截图：
  ```python
  bag = ["钻石", "金锭", "面包", "铁剑", "苹果"]

  for i, item in enumerate(bag):
      print("第", i, "格是：", item)
  ```
- 输出 5 行。加分做法：再截一张 pythontutor 单步图，动态展示 `i` 和 `item` 在每一轮怎么同步变化——比看讲解直观 10 倍。

## 图7【概念图·加分】append / remove 动态示意（excalidraw）
- **插入位置**：「加一样、扔一样」节
- 横向三格 + 动作箭头：
  - ① 起始：4 个格子 `钻石 / 金锭 / 面包 / 铁剑`，顶部标 `bag.append("苹果")`。
  - ② 中间：从右侧空气中掉下来一个苹果方块，箭头指向格子最右侧空位。
  - ③ 结果：5 个格子 `钻石 / 金锭 / 面包 / 铁剑 / 苹果`（苹果高亮）。
  - 下方另开一行同款三格演示 `remove("金锭")`：金锭打叉消失，后面 3 格整体向左收拢。
  - 顶部标题：`append 从右边长出一格；remove 中间抽掉一格，后面自动挪`。
- Export PNG。做成 GIF：三格分别导出用图片转 GIF 工具 1.5 秒/帧（非必需）。

## 图8【总结卡·加分】今天你学会了（Canva/创客贴）
- **插入位置**：「今天你学会了」节
- 沿用系列固定竖版模板（3:4），编号改「第 5 课」，7 条要点：
  - 📦 列表 `[]`：一排格子按顺序放东西
  - 0️⃣ 下标从 0 开始（`bag[-1]` 是最后一格）
  - 🚫 越界 `IndexError`：伸手掏不存在的格子
  - 🔁 遍历 `for x in bag`：一句话过完每一格
  - 🔢 `enumerate`：同时拿下标 + 内容
  - ➕ `append` 加 / ➖ `remove` 扔 / ✏️ `bag[i]=…` 换
  - 📏 `len(bag)`：现在有几样
- 底部品牌栏 + 公众号名。保持与第 1–4 课卡片同一模板。
