## 图3【概念图·必配】`.sort()` vs `sorted(...)`（excalidraw）
- **插入位置**：讲完两个工具之后（"工具二"节末尾）
- 顶部标题：`.sort() vs sorted() —— 一个动手改，一个拷贝改`
- 画左右两栏对比：
  - **左栏「.sort() —— 原地改」**（浅蓝底）
    - 画一个大方形代表 `loot` 箱子，里面装 `[3, 12, 1, 8, 5]`。
    - 代码框：`loot.sort()`
    - 一条弯曲箭头绕回 loot 本身，箭头中间标"就地重排"。
    - 箱子里的数字变成 `[1, 3, 5, 8, 12]`。
    - 旁边小字警告：`⚠️ 没返回值，接住是 None`。
  - **右栏「sorted(...) —— 拷贝改」**（浅黄底）
    - 左边一个 `loot` 箱子，里面是 `[3, 12, 1, 8, 5]`。
    - 一台"复印机"从 loot 复制出一份，送进 sort 机器，产出一个新箱子 `new_loot`，里面是 `[1, 3, 5, 8, 12]`。
    - 原 `loot` 箱子内容**不变**，用绿色勾住"原样"。
    - 代码框：`new_loot = sorted(loot)`
    - 旁边小字提醒：`✅ 有返回值，必须接住`。
- 底部注：`选原地就用 .sort()，想保留原列表就用 sorted()。跟上一课 .replace 一个套路——返回值不接就白忙。`
- 导出 PNG。

## 图4【概念图·加分】`key=` 参数怎么工作（excalidraw）
- **插入位置**：讲 `key=len` 那段
- 顶部标题：`key = 排序前先给每个元素"打分"`
- 画一条流水线：
  - 输入端：一列词 `["苦力怕", "钻石", "铁", "末影龙", "僵尸"]`，5 个方块横排。
  - 每个方块下方画一个箭头指向一台"打分机器"，机器上标 `len`。
  - 打分机器下方分别输出 5 个数字 `[3, 2, 1, 3, 2]`。
  - 数字再流进一台大排序机（写着 `sort by score`），排序按数字升序。
  - 排序机右边输出结果：`['铁', '钻石', '僵尸', '苦力怕', '末影龙']`。
- 底部注：`key 只负责"打分"，Python 按分数排；换一个打分机器 = 换一个排序标准`。
- 导出 PNG。

## 图5【运行截图·加分】数字列表 sort / sorted / reverse
- **插入位置**：讲完 `reverse=True` 揭晓开场答案之后
- 用 https://www.online-python.com 或 https://pythontutor.com，代码：
  ```python
  loot = [3, 12, 1, 8, 5]

  loot.sort()
  print("升序：", loot)

  print("降序：", sorted([3, 12, 1, 8, 5], reverse=True))

  print("原 loot 现在是：", loot)
  ```
- 输出：
  ```
  升序： [1, 3, 5, 8, 12]
  降序： [12, 8, 5, 3, 1]
  原 loot 现在是： [1, 3, 5, 8, 12]
  ```
- 截「代码 + 输出」整屏，字号调大，配色与全系列一致。

## 图6【运行截图·必配】按稀有度排背包
- **插入位置**：「拼起来：按稀有度排背包」节末尾
- 代码：
  ```python
  bag = [
      ["钻石",    3, 5],
      ["铁锭",   12, 2],
      ["末影珍珠", 1, 4],
      ["烂肉",    8, 1],
      ["金锭",    5, 3],
  ]

  def by_rarity(item):
      return item[2]

  bag.sort(key=by_rarity, reverse=True)

  for item in bag:
      print(item)
  ```
- 输出：
  ```
  ['钻石', 3, 5]
  ['末影珍珠', 1, 4]
  ['金锭', 5, 3]
  ['铁锭', 12, 2]
  ['烂肉', 8, 1]
  ```
- 截整屏。这张图串联了第 5 课列表、第 6 课函数、第 8 课排序，值得给读者看清楚。
