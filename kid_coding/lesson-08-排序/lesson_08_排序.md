## 史蒂夫的新麻烦

打了一晚上怪，史蒂夫回到家一看背包——完了。

钻石 3 个、铁锭 12 个、末影珍珠 1 个、腐肉 8 个、金锭 5 个……格子里塞得乱七八糟，想找什么都得翻半天。他很想按"数量多的排前面"、或者"稀有度高的排前面"整理一下，但一件件手动挪，太慢了。

翻译成人话：**排序（sort）就是"把一堆东西按某个规则从小到大或从大到小排好队"**。这是信奥赛里出现频率最高的操作之一，Python 已经把最厉害的排序算法帮你写好了，你只要**会用**就行。

今天要学的是**四个开关**：

- **`.sort()`**——直接把列表本身排好
- **`sorted(...)`**——返回一个新列表，原列表不动
- **`reverse=True`**——从大到小（默认是从小到大）
- **`key=某个函数`**——告诉 Python"按什么排"

故事线接一下：学会字符串处理，史蒂夫能造聊天审核机；学会排序，他终于能造**第一台真正的"背包自动整理器"**。

## 工具一：`.sort()`——原地整理（I-do）

先看最简单的：一列数字，从小到大排好。

```python
loot = [3, 12, 1, 8, 5]

loot.sort()
print(loot)
```

输出：

```
[1, 3, 5, 8, 12]
```

翻译成人话：**`列表.sort()` = 「把这个列表本身，按从小到大重新排好」。** 它没有返回值，改的是列表**自己**。

这里有个容易踩的坑，我提前给你打上警示灯：

```python
loot = [3, 12, 1, 8, 5]
result = loot.sort()      # 想接住返回值
print(result)             # 却什么也没有
```

输出：

```
None
```

`None` 翻译成人话就是"啥也没有"。**`.sort()` 不返回新列表，你想接也接不到东西**。这跟第 6 课的函数遥相呼应——那些"只干活、不返回"的函数，写 `return` 就等于 `return None`。

## 工具二：`sorted(...)`——返回新列表（I-do）

有时候你**不想**动原列表，只想拿一份排好的副本看看。这时用 `sorted`：

```python
loot = [3, 12, 1, 8, 5]

new_loot = sorted(loot)

print("新列表：", new_loot)
print("原列表：", loot)
```

输出：

```
新列表： [1, 3, 5, 8, 12]
原列表： [3, 12, 1, 8, 5]
```

翻译成人话：**`sorted(列表)` = 「拷一份，排好，还给你；原来的列表一根汗毛都不动。」**

看出规律了吗？这跟上一课的 `.replace` 是一个套路：

- `.replace` 返回新字符串，**必须接住**才有用。
- `sorted` 返回新列表，**必须接住**才有用。
- `.sort` 是**原地**改动，**不用接**，接了反而是空的。

**一句话总结**：想留档原列表就用 `sorted`，不在乎原列表就用 `.sort()`。选错了不会出错，但会白忙一场。

## 工具三：`reverse=True`——从大到小（I-do）

默认是从小到大（升序）。想从大到小（降序），加一个开关：

```python
loot = [3, 12, 1, 8, 5]

loot.sort(reverse=True)
print(loot)

print(sorted([3, 12, 1, 8, 5], reverse=True))
```

输出：

```
[12, 8, 5, 3, 1]
[12, 8, 5, 3, 1]
```

翻译成人话：**`reverse=True` = 「反过来」**。你写不写 `reverse=False` 都一样，因为默认就是从小到大。

顺手把开场的猜题揭晓：

```
[1, 3, 5, 8, 12]
[12, 8, 5, 3, 1]
[1, 3, 5, 8, 12]
```

第一行：`loot.sort()` 原地把 loot 排成升序，打印 loot 就是升序。
第二行：`sorted(..., reverse=True)` 对新列表降序排。
第三行：**再次打印 loot**——它还是第一次排完的升序，因为 `sorted` 没动它。

## 工具四：`key=`——你想按什么排？（I-do）

数字排序，谁大谁小一目了然。可如果我给你一列**字符串**呢？

```python
words = ["苦力怕", "钻石", "铁", "末影龙", "僵尸"]
words.sort()
print(words)
```

输出（大概长这样，跟系统有关）：

```
['僵尸', '末影龙', '苦力怕', '钻石', '铁']
```

这是按什么排的？——**按每个字的编码顺序**（可以粗略当成"按字典序"）。这个默认排法多数时候没啥用，我们其实想按**字数长短**来排。

这时就要动用最强的开关——`key=`：

```python
words = ["苦力怕", "钻石", "铁", "末影龙", "僵尸"]

words.sort(key=len)
print(words)
```

输出：

```
['铁', '钻石', '僵尸', '苦力怕', '末影龙']
```

翻译成人话：**`key=len` = 「排的时候，别看这个词本身，去看它的长度（`len`）」**。`len` 是一个内置函数（上一课量长度时用过），传给 `key`，Python 就会把每个词先"过一遍 len"再比较。

你也可以自己写一个"评分函数"当 key。规则很简单：**这个函数要接收一个元素，返回一个"用来比大小"的数或字符串**。

```python
def name_length(word):
    return len(word)

words = ["苦力怕", "钻石", "铁", "末影龙", "僵尸"]
words.sort(key=name_length, reverse=True)
print(words)
```

输出：

```
['末影龙', '苦力怕', '钻石', '僵尸', '铁']
```

`name_length` 就是我们自己造的一台"给词打分的机器"（第 6 课的函数）——输入一个词，输出它的长度。`key` 就是负责把机器接到 sort 上的插座。

## 拼起来：按稀有度排背包（I-do 收尾）

现在把它们全部拼起来，帮史蒂夫整理背包。每件战利品要记三样东西——**名字、数量、稀有度**。我们用一个**列表套列表**来存：

```python
bag = [
    ["钻石",    3, 5],
    ["铁锭",   12, 2],
    ["末影珍珠", 1, 4],
    ["腐肉",    8, 1],
    ["金锭",    5, 3],
]
```

内层每个小列表长这样：`[名字, 数量, 稀有度]`。数字越大，稀有度越高。

**任务 1：按数量从多到少排。**

```python
def by_count(item):
    return item[1]     # 第 1 号是数量

bag.sort(key=by_count, reverse=True)

for item in bag:
    print(item)
```

输出：

```
['铁锭', 12, 2]
['腐肉', 8, 1]
['金锭', 5, 3]
['钻石', 3, 5]
['末影珍珠', 1, 4]
```

翻译成人话：**`item[1]` 就是每一小格里的"数量"**（下标从 0 开始，还记得吧？第 5 课讲过）。`by_count` 接过一格战利品、返回它的数量，`sort` 拿着这堆数量去比大小。

**任务 2：按稀有度从高到低排。**

只要换一个评分函数——看**第 2 号**（稀有度）：

```python
def by_rarity(item):
    return item[2]

bag.sort(key=by_rarity, reverse=True)

for item in bag:
    print(item)
```

输出：

```
['钻石', 3, 5]
['末影珍珠', 1, 4]
['金锭', 5, 3]
['铁锭', 12, 2]
['腐肉', 8, 1]
```

钻石顶到最前面了，腐肉沉到底——史蒂夫的自动整理器正式上线。

**再多想一步**：如果两件物品稀有度一样，谁在前？Python 会保留它们**原来的相对顺序**（这叫"稳定排序"，术语不重要，先记住"平手时按原顺序"就够了）。所以你想"稀有度相同的按数量从多到少"，只需要**先按数量排，再按稀有度排**——两次排序一层套一层，就是背包整理的进阶技巧。

## 今天你学会了

- **`.sort()`**：把列表**本身**从小到大排好，**没有返回值**（接住的是 `None`）
- **`sorted(列表)`**：返回一个排好的**新列表**，原列表不动，**必须接住**
- **`reverse=True`**：从大到小排；不写就是从小到大
- **`key=某函数`**：告诉排序"按什么标准"——`key=len` 按长度，`key=自己的函数` 按你想要的任何规则
- **`key` 函数的规矩**：接收一个元素，返回一个用来比大小的值
- **列表套列表**：`bag[i][j]` 就是第 i 件东西的第 j 号信息（下标从 0 开始）
- **平手规则**：Python 排序是"稳定"的——两个 key 相同的元素会保持原来的先后顺序

**一句话总结**：排序 = "选一个标准（key），选一个方向（reverse），交给 Python 干活。"

排序是**每一场信奥赛都会考的高频操作**——排学生成绩、排比赛得分、排任务优先级……本质都是这四个开关。今天你用的是 Python 已经写好的排序（背后是一个非常聪明的算法），到了**第 20 课**，我们会亲手写一遍最经典的两种排序——冒泡和选择，让你彻底看穿 Python 帮你做了什么。
