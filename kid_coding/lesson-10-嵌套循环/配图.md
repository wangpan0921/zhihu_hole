## 图2【概念图·加分】从一维到二维(excalidraw)
- **插入位置**:「从"排一行"到"铺一片"」节开头,讲维度升级处
- 打开 https://excalidraw.com:
  - 左半:标题 `一维:一个 for` —— 画横向 8 个连续小方块(带序号 0~7),下方标注 `for j in range(8):`。
  - 右半:标题 `二维:for 里套 for` —— 画一个 5×8 的网格(横 8 竖 5),每个格子写 `(i,j)` 的极简坐标(可以只在四个角写清楚,其余留空表示"密密麻麻"),下方标注:
    ```
    for i in range(5):
        for j in range(8):
    ```
  - 中间画一个粗粗的箭头,写「升维」。
  - 底部注:`一根 for 铺一行,两根 for 铺一片。`
  - Sloppiness 中间档 → Export PNG,白底。

## 图3【概念图·必配】外层 × 内层 拆解(excalidraw)
- **插入位置**:「第一步:让电脑先'走一遍'网格」节末尾,讲"3 × 4 = 12"处
- 顶部标题:`for i in range(3):  for j in range(4):  外层 × 内层 = 12 次`
- 中间画一个 3 行 × 4 列的网格,每个格子按遍历顺序编号 1~12(1、2、3、4 在第一行,5、6、7、8 在第二行,以此类推),用一根粗曲线像画"S"形一样把 1~12 串起来(表示遍历路径:一行走完从最右回到最左,再进入下一行)。
- 左侧竖排三行标注,配合 i 变化:
  - `i = 0` → 亮起第 1 行(浅蓝底)
  - `i = 1` → 亮起第 2 行(浅黄底)
  - `i = 2` → 亮起第 3 行(浅绿底)
- 右侧标注`每一层 i` 时 `j` 从 0 走到 3,共 4 次。
- 底部大字注:`外层每转一圈,内层从头到尾完整跑一遍。`
- 导出 PNG。**这张图是本课的"灵魂图",读者看懂它,后面所有代码都秒懂**。

## 图4【概念图·加分】end="" vs print() 的区别(excalidraw)
- **插入位置**:「第一步」节 `end=" "` 讲解处
- 左右两栏对比:
  - 左栏标题:`默认 print(x) —— 打完就换行`
    - 画 3 个 print 语句依次输出,每行只有一个字符,呈竖排。
    - 标注:`每次 print 后自动换行,一行只装一个`
  - 右栏标题:`print(x, end="") —— 不换行,横着接`
    - 画同样 3 个 print,输出全挤在一行。
    - 标注:`打完不换行,想接什么接什么(空格 / 无 / 逗号)`
  - 底部注:`内层 for 用 end="" 把一行东西挤到一起,外层再用光的 print() 主动换行。`
- 导出 PNG。

## 图5【概念图·必配】看位置放不同东西(excalidraw)
- **插入位置**:「第三步:不只是铺满」节末尾
- 顶部标题:`if 判断位置,再决定放什么`
- 中间画一个 5×8 的网格:
  - 四周边框格子涂绿色(🟩),中间格子涂黑色(⬛)。
  - 用彩色虚线把"最外一圈"框出来,标注:`i == 0 or i == rows-1 or j == 0 or j == cols-1`
  - 中间空地区域标注:`else`
- 网格左侧标注行号 `i = 0, 1, 2, 3, 4`,顶部标注列号 `j = 0, 1, 2, 3, 4, 5, 6, 7`,**强调 `rows - 1 = 4`、`cols - 1 = 7`**(用红色圈出这两个"最后一行/列"的行号)。
- 底部注:`最后一行的行号不是 rows,是 rows - 1 —— 差 1 错(off-by-one)是信奥赛送分陷阱。`
- 导出 PNG。

## 图7【概念图·加分】二维列表 grid[i][j] 拆解(excalidraw)
- **插入位置**:「第四步:把网格'记下来'」节末尾
- 顶部标题:`grid[i][j] —— 两个中括号分别取行和列`
- 中间画一个 5×8 的具体网格(用第三步那个城墙 emoji 版):
  - 左侧标注行号 `i = 0 → grid[0]`(用大括号把整第 0 行"抱住"标为"第 0 行 = 一个小列表")
  - 顶部标注列号 `j = 0, 1, ..., 7`
  - 在 `(i=1, j=3)` 那一格用红色箭头指过去,标注 `grid[1][3] = "⬛"`(表示第 1 行第 3 列是空地)。
  - 在 `(i=0, j=0)` 那一格用蓝色箭头指过去,标注 `grid[0][0] = "🟩"`。
- 底部注:`grid 装着 5 个"行小列表",每个"行小列表"装着 8 个格子 —— 一维套一维就是二维。`
- 导出 PNG。

## 图8【总结卡·加分】今天你学会了(Canva/创客贴,套用系列模板)
- **插入位置**:「今天你学会了」节
- 竖版 3:4 卡片,沿用第 1 课起的固定版式(只改课号与内容):
  - 顶部:`第 10 课 · 知识清单` + 《我的世界里学编程》
  - 右上角加徽章:`第二阶段 · 进阶关 · 开篇`(与第 9 课"第一阶段·完"呼应)
  - 6 条要点(每条配 emoji):
    - 🔁 嵌套循环 = 循环套循环,**外层 × 内层 = 总次数**
    - 📐 外层管行 `i`,内层管列 `j`,内层跑完 `print()` 换行
    - ➡️ `print(..., end="")` —— 打完不换行
    - 🎨 `if` + `i, j` 看位置,画边框 / 对角线 / 任何图案
    - 🧱 `grid[i][j]` —— 二维列表,两个中括号取行与列
    - ⚠️ 差 1 错 —— 最后一行是 `rows - 1`,不是 `rows`
  - 底部:品牌栏 + 公众号名。
