# 一句话盖起一座城墙：嵌套循环，让电脑帮你铺 N×M 地图

> 这是《我的世界里学编程》系列的第 10 篇，也是**第二阶段·进阶关**的开篇。**上期回顾**：上一课我们把前 8 课的家伙全抬出来，还原了一整场**僵尸围城战**。史蒂夫勉强扛了几回合、最后还是倒下了——一场几乎必输的仗告诉他：光靠一把剑不够，**得把家园围起来**。这一课，就教他怎么**用一小段代码盖起一整堵城墙**。

## 先猜猜看

老规矩，先别往下拉。心里跑一遍这段代码——猜猜它一共会打印**几行**？最后一行长什么样？

```python
for i in range(3):
    for j in range(4):
        print(i, j)
```

（提示：**外面的 `for` 每转一次，里面的 `for` 会从头到尾完整跑一整轮**。）

猜好了记在心里，等下 I-do 一起验。

## 从"排一行"到"铺一片"

前几课我们用 `for` 干过不少事：刷一百只怪、盖一排方块、发一次奖励——**一维**的重复。可《我的世界》是**三维**的，光地面就是一整片二维网格：你想铺 5 行 8 列的石板路、盖一堵 10 格宽 4 格高的城墙，光一个 `for` 就不够了。

想象你是包工头，让工人小张去铺地板。你会怎么下命令？

> "**从第 1 行开始**——**第 1 行从左往右一格一格铺完**;铺完之后**换到第 2 行**——**第 2 行也从左往右一格一格铺完**;**再第 3 行、第 4 行**……直到最后一行。"

看出结构了吗?**外层管"第几行",内层管"这一行里的第几格"**。翻译成代码——**一个 `for` 套一个 `for`**,这就是今天的主角:

**嵌套循环(nested loop)**。翻译成人话:**循环里面再放一个循环,外层每转一圈,内层从头到尾完整跑一遍**。

## 第一步:让电脑先"走一遍"网格(I-do)

`range(3)` 依次给出 `0, 1, 2`(第 3 课学过:从 0 开始、不含结束值)。所以下面这段就是**"3 行 × 4 列"的坐标遍历**:

```python
for i in range(3):          # i 是行号:0、1、2
    for j in range(4):      # j 是列号:0、1、2、3
        print("(", i, ",", j, ")", end=" ")
    print()                 # 一行铺完,主动换行
```

运行结果(正好 3 行、每行 4 个坐标):

```
( 0 , 0 ) ( 0 , 1 ) ( 0 , 2 ) ( 0 , 3 ) 
( 1 , 0 ) ( 1 , 1 ) ( 1 , 2 ) ( 1 , 3 ) 
( 2 , 0 ) ( 2 , 1 ) ( 2 , 2 ) ( 2 , 3 ) 
```

几个小玄机说清楚:

- `i` 走 3 次、`j` 每次走 4 次——**总共打印 3 × 4 = 12 个坐标**。开场那道题也是同一个算法:**12 次、最后一次是 `2 3`**。**外层 × 内层 = 总次数**——这是嵌套循环最值钱的直觉。
- `print(..., end=" ")` 里那句 `end=" "`——**告诉 `print` 别自动换行、末尾接一个空格就完事**。翻译成人话:**默认 `print` 打完自己换行,`end=" "` 就是"打完接空格不换行"**,我们才能把一行 4 个坐标挤在同一行里。
- 内层跑完后那句**光秃秃的 `print()`**——**没参数、就是主动换一行**。一行铺完、接下一行。

**记住这个结构**:外层管行、内层管列、内层跑完 `print()` 换行。今天所有代码都是它的变形。

## 第二步:把坐标换成方块,城墙就浮现了(I-do)

坐标看着抽象——把每个 `(i, j)` 换成一个方块字符,一整片地图立刻就出来了。史蒂夫的第一件工程是**铺一片 5 行 8 列的石板地**:

```python
rows = 5
cols = 8

for i in range(rows):
    for j in range(cols):
        print("🟫", end="")   # 每格盖一个方块,紧挨着不留空
    print()
```

跑出来是一片**紧挨着的 5×8 石板地**:

```
🟫🟫🟫🟫🟫🟫🟫🟫
🟫🟫🟫🟫🟫🟫🟫🟫
🟫🟫🟫🟫🟫🟫🟫🟫
🟫🟫🟫🟫🟫🟫🟫🟫
🟫🟫🟫🟫🟫🟫🟫🟫
```

**只改两个数(`rows`、`cols`)就能铺任意大小的地图**——这才是循环真正的威力。史蒂夫要盖一整个 20×30 的农场?把 5、8 换成 20、30 就行,代码**一个字都不用动**。

## 第三步:不只是铺满——学会"看位置"(I-do)

真正的城墙不是"每格都一样"的。**边上是石墙、中间是空地**,才叫围起来。这时候第 2 课的 `if` 就派上用场了——**"看当前是第几行第几列、再决定放什么"**:

```python
rows = 5
cols = 8

for i in range(rows):
    for j in range(cols):
        if i == 0 or i == rows - 1 or j == 0 or j == cols - 1:
            print("🟩", end=" ")   # 边界 = 城墙
        else:
            print("⬛", end=" ")   # 里面 = 空地
    print()
```

运行结果——**一座 5×8 的城墙**,四周绿色石砖、中间黑色空地:

```
🟩🟩🟩🟩🟩🟩🟩🟩
🟩⬛⬛⬛⬛⬛⬛🟩
🟩⬛⬛⬛⬛⬛⬛🟩
🟩⬛⬛⬛⬛⬛⬛🟩
🟩🟩🟩🟩🟩🟩🟩🟩
```

翻译成人话,那句长长的 `if` 到底在问什么:

- `i == 0`:**第一行**(最上面一排)
- `i == rows - 1`:**最后一行**(`rows - 1` 是最后一行的行号——因为 `range` 从 0 开始,5 行的行号只有 0、1、2、3、4)
- `j == 0` / `j == cols - 1`:**最左列 / 最右列**
- 四个条件用 `or` 连起来——**只要任意一个成立**,这一格就是墙

`or` 就是第 2 课的**布尔逻辑**——**多个条件里只要一个真、整体就真**。四条边全靠这一行 `or` 拼出来。

**新手最容易栽的坑**:把 `rows - 1` 写成 `rows`。**记住:`range(rows)` 只走到 `rows - 1`,所以"最后一行的行号"就是 `rows - 1`**。这个坑叫**差 1 错(off-by-one)**,信奥赛判卷最爱的送分陷阱——今天摔一次、以后就长记性。

## 第四步:把网格"记下来"——二维列表(I-do)

前面都是**边算边打印**——算完就没了。可城墙一旦盖好,史蒂夫要走过来走过去、僵尸砸掉一块砖……**得能记下来、能改**才行。这就要用到第 5 课的老朋友、**升级版本**:**二维列表**——**列表套列表**(第 9 课我们用它装过一队僵尸,还记得吗?)。

翻译成人话:**一维列表是一排格子、二维列表是一片格子**——外面的大列表装着"每一行",每一行本身又是一个小列表装着"这行里的每一格"。

我们把上一段的城墙**装进一个二维列表**、再打印出来:

```python
rows = 5
cols = 8

# 第一段:造一片空地图(全是空地 "⬛")
grid = []
for i in range(rows):
    row = []                         # 造这一行的小列表
    for j in range(cols):
        row.append("⬛")
    grid.append(row)                 # 把这一行装进大列表

# 第二段:把四周改成城墙 "🟩"
for i in range(rows):
    for j in range(cols):
        if i == 0 or i == rows - 1 or j == 0 or j == cols - 1:
            grid[i][j] = "🟩"

# 第三段:把网格画出来
for i in range(rows):
    for j in range(cols):
        print(grid[i][j], end="")
    print()
```

看清 `grid[i][j]` 是什么了吗?

- `grid` 是大列表、`grid[i]` 是**第 i 行**(本身也是个小列表)
- `grid[i][j]` 才是**第 i 行、第 j 列的那一格**——**两个中括号**分别拿到"行"和"列"

**"造网格 → 改网格 → 画网格"**——这三段独立的嵌套循环,是本课的**看家结构**。以后走迷宫、扫雷、俄罗斯方块……**全是它的变形**。

顺手把开场那道题揭晓:`for i in range(3)` 走 3 次、`for j in range(4)` 每次走 4 次,一共打印 `3 × 4 = 12` 行;最后一行的 `i = 2, j = 3`,所以是 `2 3`。**外层 × 内层**——记住这个乘法,你就永远不会数错循环次数。

## 一起改改看(We-do)

轮到你上场——每一改都**先预测、再运行**,你的第六感比你想的准。

**改动 1**:把 `rows = 5, cols = 8` 改成 `rows = 3, cols = 3`。

> **先预测**:这时候城墙会长什么样?**中间还有"空地"吗**?

> **揭晓**:中间还会有 **1 格空地**。3×3 一共有 9 格,四条边占掉外围 8 格,只留下正中心的 1 格。如果继续缩成 2×2,四格就全是边界,空地才会完全消失。这在信奥赛里叫**边界情况(corner case)**,专门考"你有没有想到极端输入"。

**改动 2**:把长长的 `if` 拆成两半——
```python
if i == 0 or i == rows - 1:
    print("🟩", end="")
elif j == 0 or j == cols - 1:
    print("🟩", end="")
else:
    print("⬛", end="")
```
预测:**结果会一样吗**?想清楚 `elif` 和 `or` 有没有本质区别。(提示:结果**一模一样**,但**表达方式不同**——两种写法都对,你更喜欢哪一种?)

**改动 3**:**给城墙加一扇门**——把最下面一排正中间那一格改成 `"🟨"`(黄色木门)。改在哪一段?
> 小提示:**画网格之前**加一行 `grid[rows - 1][cols // 2] = "🟨"`。`//` 是**整数除法**——`8 // 2 = 4`,正好是最下面一行的中间列。翻译成人话:`//` 就是"除完之后砍掉小数点"。

**改动 4(挑战一下自己)**:把城墙**改成对角线**——只有 `i == j` 的格子放 `"🟩"`、其它都是 `"⬛"`。跑一次,你会看到一条从左上斜到右下的墙——**只改一处 if 条件、图案就完全变了**。这就是嵌套循环最迷人的地方:**外面的骨架不动、里面的判断一换、画面就变**。

改完回头想一件事——**你每一次只碰了整份代码里"很小的一块"**:改大小只动了两个数、加门只动了一行、改对角线只动了 `if`。这就是**"骨架 + 微调"**的编程思路,越往后越吃这一套。

## 今天你学会了

- **嵌套循环 = 循环里放循环**:**外层每转一圈、内层从头跑到尾**。总次数 = 外层次数 × 内层次数。
- **两个 `for` 的经典分工**:**外层管行 `i`、内层管列 `j`**;内层跑完、外层的 `print()` 空一行换行。
- **`print(..., end="")`**:让 `print` 打完**不换行**——想把一行东西挤在一行里就靠它。
- **看位置放不同的东西**:靠 `if` + `i, j` 判断"在第几行第几列",就能画边框、画对角线、画任何图案。
- **二维列表 `grid[i][j]`**:**列表套列表**记住整片地图——**两个中括号**分别取行和列。
- **差 1 错 (off-by-one)**:最后一行的行号是 `rows - 1`,不是 `rows`;`range(n)` 只走到 `n - 1`。信奥赛送分陷阱、要牢记。
- **"造网格 → 改网格 → 画网格"三段式**:本课的看家结构、也是后面所有网格题的通用套路。

**一句话总结**:嵌套循环不是"新东西"——就是**你已经会的 `for`、套上一层**。真正难的不是语法,而是**分清"外层在做什么、内层在做什么"**——这个功夫一养成,后面**迷宫、扫雷、贪吃蛇**都是同一个骨架。

## 课后挑战

**🟢 基础关**

在完整代码的基础上做三件事:

1. 把地图改成 `rows = 8, cols = 15`,盖一座**更长的城堡**——**只改两个数、代码不动**。
2. **加两扇门**:底边正中、顶边正中各一扇 `"🟨"`。(提示:`grid[0][cols // 2]` 和 `grid[rows - 1][cols // 2]`)
3. **在城墙内部撒 3 棵树**——先直接写死坐标就行,比如 `grid[2][3] = "🌲"`、`grid[3][6] = "🌲"`、`grid[4][10] = "🌲"`。写三行、看看效果。

**🔴 进阶关**

给城墙**加一层护城河**——**外圈两层**:**最外一圈是水 🟦、往里一圈是石墙 🟩、再往里才是空地**。

> 小提示:判断"最外一圈"用 `i == 0 or i == rows - 1 or j == 0 or j == cols - 1`;判断"第二圈"稍难一点——**"不是最外圈、但离边只差一格"**。想一想 `i == 1 or i == rows - 2 or j == 1 or j == cols - 2` 加上"不是最外圈"这个前提怎么写?可以用 `if / elif / else` 一层层剥。

**加分挑战**:写一个函数 `draw_wall(rows, cols)`——**给它长宽、就自动画一座带门的城墙**。第 6 课学过函数——**把整段代码打包、只留 `rows, cols` 两个参数**。以后史蒂夫要盖 10 座不同大小的哨塔,一行 `draw_wall(...)` 一座、**代码不用复制粘贴**——**这就是"程序员越懒、代码越强"的秘诀**。
