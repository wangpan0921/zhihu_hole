## 图2【概念图·加分】套娃盒子 = 递归的直觉(excalidraw)
- **插入位置**:「从『打开套娃盒子』讲起」节,那句「拆开当前这个盒子……」的引用块之前
- 打开 https://excalidraw.com:
  - 横向画 5 个大小递减的方形盒子,一个套一个:最外的大红盒子里嵌一个略小的橙盒子,再嵌黄、绿、蓝,最里面最小的蓝盒子里画一个 ✨ 星星表示「空 = 到底」。
  - 每个盒子右上角标 `第 5 层 / 第 4 层 / 第 3 层 / 第 2 层 / 第 1 层`。
  - 最外面用一个圆圈框住整只套娃,旁边写代码风的伪语句 `open(box):`,再向内画一个虚线小圈框住次外层,旁边写 `open(next_box)`,再向内框住下一层写 `open(next_box)`——**用重叠圆圈直观表达「函数在自己里面又叫了自己一次」**。
  - 顶部大标题:`递归 = 用同一招,拆掉里面那个更小的自己`。
  - 底部口号条:`一个函数,遇到「里面还是同一件事」,就再叫一次自己`。
  - Sloppiness 选中间档(手绘亲切感)→ Export PNG,白底。

## 图3【概念图·必配】递归两条铁律:底 + 自己叫自己(excalidraw)
- **插入位置**:「递归的两条铁律」节,`explore(3)` 代码块之后、跑输出之前
- **这是本课的「灵魂图」**,画一张对称的双栏卡片:
  - 顶部大标题:`递归的两条铁律 —— 缺一不可`。
  - 左栏(蓝底 ·「底」):画一个大大的红色停车标志/刹车片,标题 `① 底 (base case)`;下方写 `if depth == 0: return`,再配一行小字「翻译成人话:走到头的条件」;底部提示语 `⚠ 没有它 = 无限递归,直接翻车`。
  - 右栏(橙底 ·「自己叫自己」):画一个大大的绿色油门/加速符号,标题 `② 自己叫自己 (recursive case)`;下方写 `explore(depth - 1)`,配一行小字「翻译成人话:让盒子越来越小」;底部提示语 `⚠ 每次都要更靠近「底」,否则永远到不了头`。
  - 中间竖着一行大字:`刹车 + 油门,程序才跑得稳`。
  - 导出 PNG。
- **说明**:这张图今后凡是复习/串讲递归都可复用,是全系列长期资产。

## 图4【运行截图·加分】explore(3) 完整输出
- **插入位置**:「递归的两条铁律」节,`现在跑一下 explore(3):` 那段话之后
- 打开 https://www.online-python.com,粘贴完整的 `explore` 函数(带 `if depth == 0` 底),尾部调用 `explore(3)`。
- 运行输出:
  ```
  进入第 3 层洞穴
  进入第 2 层洞穴
  进入第 1 层洞穴
  到底了,返回
  退出第 1 层洞穴
  退出第 2 层洞穴
  退出第 3 层洞穴
  ```
- 截「代码 + 输出」整屏,字号调大。用红笔在左侧标注上半段 `进入 3 → 2 → 1`,在下半段 `退出 1 → 2 → 3`——**帮读者一眼看到「先进后出」的对称美**。全系列统一编辑器与配色。

## 图5【运行截图·加分】We-do:改一个数,少 2 行
- **插入位置**:「一起改改看」节,`好了,运行一下:` 那句话之后
- 打开同一个 https://www.online-python.com 会话,仅把 `explore(3)` 改成 `explore(2)` 再次运行。
- 运行输出:
  ```
  进入第 2 层洞穴
  进入第 1 层洞穴
  到底了,返回
  退出第 1 层洞穴
  退出第 2 层洞穴
  ```
- 用红笔在改动那行画箭头,标「只改这一处」;在输出上方画个大字「5 行」,和上一张的「7 行」做视觉对比。

## 图6【运行截图·必配】无限递归:RecursionError 翻车现场
- **插入位置**:「一起改改看」节末尾,`跑一下,你会看到屏幕刷刷刷……` 那段话之后
- 粘贴**删掉 base case** 后的版本,尾部调 `explore(3)`,运行。屏幕会打印超长一串「进入第 X 层洞穴」,最后停在:
  ```
  ...
  进入第 -996 层洞穴
  进入第 -997 层洞穴
  RecursionError: maximum recursion depth exceeded
  ```
- 截图重点:**红色报错信息 + 屏幕上被刷屏的一串"进入第 -xxx 层"**——**视觉张力最强的一张**,一眼让读者对"忘写底 = 翻车"留下条件反射。
- 用红笔在报错处画个大圈,旁边贴个 emoji 💥 表情。

## 图7【概念图·加分】先进后出 = 一叠盘子(excalidraw)
- **插入位置**:「递归的两条铁律」节,输出 7 行之后、`翻译成人话:递归天生就是「先钻进去,再原路撤出来」` 那段话旁
- 画一叠盘子从下往上码高:
  - 最底盘子写 `explore(3)` · 时间点 `t1 进入`,盘沿写「先放」;
  - 再上一盘 `explore(2)` · `t2 进入`;
  - 再上一盘 `explore(1)` · `t3 进入`;
  - 顶上最后一盘 `explore(0)` · `t4 到底`,写「翻个面往回撤」。
  - 右侧竖一条时间轴,从上往下依次箭头标:`t5 explore(1) 退出 → t6 explore(2) 退出 → t7 explore(3) 退出`——**上层先撤,下层后撤**。
  - 顶部大标题:`递归 = 一叠盘子:后放的先拿`。
  - 底部口号条:`去时 A → B → C,回时 C → B → A`。
  - 导出 PNG。
