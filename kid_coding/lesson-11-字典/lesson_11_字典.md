# 第 11 篇：给每种矿石贴价签：字典 dict，让每样东西都有自己的名字

> 这是《我的世界里学编程》系列的第 11 篇，**第二阶段·进阶关**第 2 讲。**上期回顾**：上一课我们用嵌套循环给史蒂夫盖起了一座 5×8 的城墙——四周🟩、中间⬛、还开了一扇木门。家园终于围起来了。可仓库里堆着各种矿石——钻石、金锭、铁块、绿宝石、红石粉——**电脑要怎么记住「钻石一颗值 8 金币、铁一块值 3 金币」这种「一一对应」的关系**呢？今天请出列表的升级版兄弟：**字典（dict）**。

## 先猜猜看

老规矩，先别往下拉。心里跑一遍这段代码——猜猜它会打印**几行**、**分别输出什么**？

```python
bag = {"钻石": 3, "铁块": 12}
bag["金锭"] = 5
bag["钻石"] = bag["钻石"] + 1
print(bag["钻石"])
print(bag["金锭"])
print(len(bag))
```

（提示：**每一行都要在脑子里「看看袋子里现在有啥」**——`bag["钻石"] = bag["钻石"] + 1` 跟第 1 课的 `gold = gold + 10` 是一家人。）

猜好了记在心里，等下 I-do 一起验。

## 用列表装矿石？好像哪里不对

前面第 5 课我们学过**列表**：一排格子，靠**下标**取东西。用它记矿石好像也行：

```python
ores   = ["钻石", "金锭", "铁块"]   # 第 0 格是钻石、第 1 格是金锭……
counts = [3, 5, 12]                 # 每种各有多少
```

问题来了：史蒂夫吼一声「我还有几颗**钻石**？」——你得**先在 `ores` 里找到「钻石」在第几格，再去 `counts` 里同一格取数**。两个列表得**一直对齐**、加一种就要两边同时改——**多容易漏、多容易错位**。

真实生活里我们从来不这么干。你查英汉词典查「apple」的意思——**直接翻到 A 开头、找 apple**，谁会先数它是第几个词？

代码也一样。**用名字查东西**这种「一一对应」的关系，Python 里有专门的家伙——**字典（dictionary，简称 dict）**。翻译成人话：**一个装「键 → 值」配对的袋子，用「键」当便利贴，直接掏出对应的「值」**。

## 第一步：造一个字典（I-do）

字典用**大括号 `{}`** 包起来，每对元素写成 `键: 值`，配对之间用**逗号**隔开：

```python
prices = {"钻石": 8, "金锭": 4, "铁块": 3, "绿宝石": 10}
```

一行代码，史蒂夫的价目表就贴好了。三个关键词一次讲清：

- **键（key）**——那张便利贴上写的名字，这里是 `"钻石"`、`"金锭"` 这些**字符串**。翻译成人话：**你用来找东西的暗号**。
- **值（value）**——便利贴对应的内容，这里是价格 `8`、`4`、`3`、`10`。翻译成人话：**暗号背后藏着的宝贝**。
- **键值对（key-value pair）**——一张便利贴加一个宝贝，合起来就是一对。字典就是一堆键值对的集合。

想查「钻石多少钱」？**用中括号 + 键**，一步到位：

```python
print(prices["钻石"])      # 输出：8
print(prices["绿宝石"])    # 输出：10
```

**跟列表长得像、但里面填的完全不一样**——列表填**数字下标**（`ores[0]`），字典填**键**（`prices["钻石"]`）。**列表靠位置、字典靠名字**——这句话记牢，今天就赢一半。

## 第二步：加、改、删（I-do）

价目表不是死的。**新收了一种矿、要涨价、要下架**——字典都能改：

```python
prices = {"钻石": 8, "金锭": 4, "铁块": 3}

# ① 加一种：红石粉，2 金币
prices["红石粉"] = 2

# ② 改价格：钻石涨到 10
prices["钻石"] = 10

# ③ 下架：把铁块拿掉
del prices["铁块"]

print(prices)
```

输出：

```
{'钻石': 10, '金锭': 4, '红石粉': 2}
```

看清三个招式：

- **`prices["红石粉"] = 2`**——键**不存在**就是「新增」。
- **`prices["钻石"] = 10`**——键**已存在**就是「覆盖旧值」。
- **`del prices["铁块"]`**——`del` 是「delete」的缩写，**把这一对整个扔掉**。翻译成人话：**撕掉这张便利贴，连里面的宝贝一起扔**。

**同一个语法（`字典[键] = 值`），既能加又能改**——这就是字典比「两个列表凑一对」省心的地方。

## 第三步：查之前先问一句「有吗？」（I-do）

新手最容易踩的坑：**去查一个「字典里根本没有的键」**。

```python
prices = {"钻石": 8, "金锭": 4}
print(prices["下界合金"])
```

跑起来直接崩：

```
KeyError: '下界合金'
```

**`KeyError`** 就是**「你查的这张便利贴根本不存在」**。信奥赛判卷里，`KeyError` 属于「运行时错误」，跟第 5 课的 `IndexError`（下标越界）是同一家族的送分陷阱。

两种稳妥办法：

**办法 A：先用 `in` 问一句**

```python
if "下界合金" in prices:
    print(prices["下界合金"])
else:
    print("这个矿还没上架")
```

`in` 就是「在不在」——翻译成人话：**「这张便利贴在袋子里吗？」** 在就用、不在就走另一条路。`in` 第 7 课在字符串里我们见过（「脏话在不在这句话里」），字典里的 `in` **只查键、不查值**——因为便利贴才是你能一眼扫到的东西。

**办法 B：用 `.get(键, 默认值)`**

```python
print(prices.get("下界合金", 0))   # 输出：0
print(prices.get("钻石", 0))       # 输出：8
```

`d.get(键, 默认值)` 的意思是：**「帮我查一下这个键，查得到就给我值、查不到就给我这个默认值」**——**不崩、还省一个 `if`**。以后写「背包里没这个矿就当 0 个」这种逻辑，一行就搞定。

## 第四步：遍历——把整本字典念一遍（I-do）

价目表贴好了，史蒂夫想**把每种矿的价格都念一遍**。列表用 `for x in ores:`，字典也一样——**默认遍历的是「键」**：

```python
prices = {"钻石": 8, "金锭": 4, "铁块": 3}

for ore in prices:
    print(ore, "值", prices[ore], "金币")
```

输出：

```
钻石 值 8 金币
金锭 值 4 金币
铁块 值 3 金币
```

**每次循环，`ore` 就是当前的一张便利贴（键）**，`prices[ore]` 就是它对应的值。三行代码把整本价目表念完。

**升级版**：同时拿到「键」和「值」，用 **`.items()`**：

```python
for ore, price in prices.items():
    print(ore, "值", price, "金币")
```

`.items()` 一次给你**两个东西**——一头是键、一头是值——所以左边写**两个名字**（`ore, price`）接住，跟第 5 课学 `enumerate` 时「一次拿两个」是一个套路。翻译成人话：**便利贴和宝贝一起给你，不用再回头取**。

## 第五步：字典里还能装什么？（I-do）

值不一定非得是数字——**任何东西都能塞进去**。给钻石装一份完整的「档案卡」：

```python
diamond = {
    "名字": "钻石",
    "价格": 8,
    "稀有度": "史诗",
    "能造": ["剑", "镐", "护甲"]
}

print(diamond["名字"], "属于", diamond["稀有度"], "级")
print("能造：", diamond["能造"])
print("第一个能造的是：", diamond["能造"][0])
```

输出：

```
钻石 属于 史诗 级
能造： ['剑', '镐', '护甲']
第一个能造的是： 剑
```

看最后一行——`diamond["能造"]` 拿出来是个**列表**，那就再套一个 `[0]` 取第一个元素。**字典里装列表、列表里装字典**——这套「数据嵌套」的思路，是后面所有「复杂数据」（角色档案、迷宫地图、技能树）的地基。以后看到「史蒂夫的完整信息」「每个僵尸的属性」，大概率就是**一个装字典的列表** 或者 **一个装列表的字典**。

顺手把开场那道题揭晓：

- `bag = {"钻石": 3, "铁块": 12}` —— 起始 2 对。
- `bag["金锭"] = 5` —— 新增，变 3 对。
- `bag["钻石"] = bag["钻石"] + 1` —— 老朋友，钻石从 3 变成 4。
- 第一行输出 `4`（钻石数量）、第二行 `5`（金锭数量）、第三行 `3`（字典里有多少对——**`len(dict)` 数的是键值对个数**，不是「所有值加起来」）。

## 一起改改看（We-do）

轮到你上场——每一改都**先预测、再运行**。

**改动 1**：把 `prices["钻石"] = 10` 改成 `prices["钻石"] = prices["钻石"] + 2`。

> **先预测**：钻石最后是几？这行跟第 1 课的 `gold = gold + 10` 有什么共同点？

> **揭晓**：钻石变成 **10**（原来 8 + 2）。共同点是——**`=` 的方向永远从右往左**、「先算右边再放进左边」，第 1 课的规矩今天照样管用。

**改动 2**：在遍历前加一行 `prices["蛋糕"] = 100`，再跑那段 `for ore, price in prices.items():`。**预测**：输出会多出哪一行、位置在哪里？

> **揭晓**：多一行 `蛋糕 值 100 金币`，通常出现在**最后**。**Python 3.7 以后，字典会记住你「插入的顺序」**——先加的先念、后加的后念。信奥赛里靠这条「插入顺序」能省不少心，但**不要**依赖它做排序（想排序请用第 8 课的 `sorted`）。

**改动 3**：把 `del prices["铁块"]` 改成 `prices.pop("铁块")`。**预测**：结果一样吗？

> **揭晓**：结果**一样**——键值对被扔掉。**但 `pop` 多送你一份礼物**：它**返回被扔掉的那个值**。写成 `gone = prices.pop("铁块")`，`gone` 就是 3（铁块原来的价格）——「下架的同时，记住它最后卖多少钱」。**`del` 是纯扔、`pop` 是「扔了顺手还给你一份」**。

**改动 4（挑战一下自己）**：把 `for ore in prices:` 改成 `for ore in sorted(prices):`。**预测**：输出顺序会怎么变？

> **揭晓**：按**键的字符顺序**输出（汉字按 Unicode 编码排、不是按拼音）。`sorted(字典)` 会把**所有键**排完序、再一个个还给你——**「字典 + 排序」的组合技，第 8 课的老朋友又回来了**。

改完回头想一件事：字典的操作**全都围着「键」转**——加改删靠键、查靠键、遍历默认给键。**键是字典的门牌号**，这句话记牢，以后写字典就不迷路。

## 今天你学会了

- **字典（dict）= 键值对的袋子**：用大括号 `{}` 包起来，`键: 值`，一对对之间用逗号隔开。**列表靠位置、字典靠名字**。
- **取值** `d[键]`、**加改** `d[键] = 值`（不存在就加、存在就覆盖）、**删** `del d[键]` 或 `d.pop(键)`。
- **查之前先问 `in`**，或者用 **`d.get(键, 默认值)`** 免于 `KeyError` 崩溃。
- **遍历**：`for k in d:` 默认给键；`for k, v in d.items():` 一次给键和值（左边写两个名字接住）。
- **值可以是任何东西**——数字、字符串、列表、甚至另一个字典。「字典里装列表、列表里装字典」是复杂数据的通用套路。
- **`len(d)`** 数的是**键值对个数**，不是「所有值加起来」。
- **Python 3.7+ 的字典记住插入顺序**——顺手用、别依赖它排序；要排序请 `sorted(d)`。

**一句话总结**：字典就是**「给每样东西起个专属名字、再用名字直接找它」**——**列表是排队、字典是点名**。以后凡是「A 对应 B」的关系——玩家名对分数、单词对翻译、坐标对方块——**十有八九用字典**。

## 课后挑战

**🟢 基础关**

在下面这份初始价目表基础上做四件事，**最后打印整个字典**：

```python
prices = {"钻石": 8, "金锭": 4, "铁块": 3, "绿宝石": 10}
```

1. **新收一种**：红石粉，价格 2 金币。
2. **涨价**：绿宝石涨到 15。
3. **下架**：把铁块删掉。
4. **查一下**：安全地查询「下界合金」的价格——**没有就打印 0**（提示：用 `.get`）。

**🔴 进阶关**

给史蒂夫做一个**「背包总价值」计算器**——已知每种矿的**价格**和**数量**两个字典，算出**背包里所有矿加起来一共值多少金币**：

```python
prices = {"钻石": 8, "金锭": 4, "铁块": 3, "绿宝石": 10}
bag    = {"钻石": 3, "铁块": 5, "绿宝石": 1}    # 金锭这次没捡到
```

> 小提示：**遍历 `bag.items()`** 拿到 `矿名, 数量`，每次把 `prices[矿名] * 数量` 累加到一个 `total = 0` 里。**注意**：`bag` 里的矿一定在 `prices` 里有吗？**不一定！** 想想史蒂夫捡到一坨「没见过的新矿石」怎么办——**用 `in` 或 `.get` 稳一手**。

**加分挑战**：把每种矿的档案（**名字 + 价格 + 稀有度**）做成**一个字典**、多个矿的档案再**装到一个列表**里，遍历这个列表，把**「稀有度是史诗」的矿石名字**全部打印出来。用到的知识：**字典 + 列表 + `for` + `if`**——前 10 课的组合拳，今天正式打通任督二脉。
