## 图2【概念图·必配】键 = 便利贴，值 = 宝贝（excalidraw）
- **插入位置**：「第一步：造一个字典」节末尾，`prices["钻石"]` 讲完之后
- 打开 https://excalidraw.com：
  - 画一个大袋子形状（浅色圆角矩形，约 700×400），袋口画一根束绳，顶部标题 `prices = { ... }`。
  - 袋子内部横向排列 4 组「便利贴 + 宝贝」配对：
    - 亮黄小便利贴写 `"钻石"` → 蓝色钻石图标块 → 大字 `8`
    - 便利贴 `"金锭"` → 金色方块 → `4`
    - 便利贴 `"铁块"` → 灰色方块 → `3`
    - 便利贴 `"绿宝石"` → 绿色方块 → `10`
  - 每对之间画一个粗箭头 `键 → 值`。
  - 袋子外面右侧画一个小人拿着写 `"钻石"` 的便利贴，用红色箭头指进袋子内的钻石那一对，标注：`prices["钻石"] → 8`。
  - 底部注：`键 = 你用来找东西的暗号；值 = 暗号背后藏着的宝贝。`
  - Sloppiness 选中间档（手绘亲切感）→ Export PNG，白底。
- **说明**：**这张是本课的「灵魂图」，读者看懂它，后面所有代码都秒懂**。

## 图6【运行截图·必配】价目表遍历输出
- **插入位置**：「第四步：遍历——把整本字典念一遍」节末尾（`.items()` 版本代码之后）
- 打开 https://www.online-python.com，粘贴：
  ```python
  prices = {"钻石": 8, "金锭": 4, "铁块": 3}

  for ore, price in prices.items():
      print(ore, "值", price, "金币")
  ```
- 运行输出：
  ```
  钻石 值 8 金币
  金锭 值 4 金币
  铁块 值 3 金币
  ```
- 截「代码 + 输出」整屏，字号调大到手机也能清楚看清。**全系列统一编辑器与配色**。**这张是本篇的「高光时刻」——第一次让读者亲眼看到「一行 for 把字典念完」**。

## 图7【概念图·加分】.items() 一次拿两个（excalidraw）
- **插入位置**：「第四步」节讲 `.items()` 处
- 上下两格对比：
  - 上格：`for ore in prices:` —— 画一个传送带，袋子里的便利贴一张张滑出来（只有键）；标注 `ore = "钻石" → ore = "金锭" → ore = "铁块"`；下方小字：`默认只给键、值要回头 prices[ore] 再取一次`。
  - 下格：`for ore, price in prices.items():` —— 传送带上每次滑出的是**一对**（便利贴 + 宝贝）；用两个手接、分别接住 `ore` 和 `price`；标注每一次：`(ore="钻石", price=8) → (ore="金锭", price=4) → (ore="铁块", price=3)`；下方小字：`一次两个，接得住就得写两个名字。`
  - 顶部标题：`.items() —— 便利贴和宝贝一起给你。`
  - 底部呼应第 5 课：`跟 enumerate 一样，「一次拿两个」的时候，左边就要写两个名字。`
  - 导出 PNG。
