# 掉进岩浆要不要扣血？——教电脑学会"做判断"

> 这是《我的世界里学编程》系列的第 2 篇。上一篇我们让史蒂夫有了会变的血量和金币；这一篇，我们要教电脑学会"看情况做决定"。目标依然远大——一路通向信息学奥赛；但今天只攻一个点：条件判断。

## 先问你一个问题

史蒂夫一脚踩进了岩浆。游戏在这一瞬间必须决定：**要不要扣血？扣多少？会不会直接烧死？**

天黑了，游戏又要决定：**该不该在你身边刷出一只僵尸？**

你发现没有——游戏每一刻都在做这种"如果……那么……"的决定。这种"看情况办事"的能力，程序里叫**条件判断**。

翻译成人话：**条件判断，就是让电脑先看一眼情况，再决定做不做某件事。**

## 最简单的判断：if

先看史蒂夫踩岩浆：

```python
in_lava = True   # 现在踩在岩浆里吗？

if in_lava:
    print("好烫！每秒扣 4 点血")
```

`if` 就是"如果"。它后面跟一个"成立还是不成立"的条件，成立就执行下面缩进的那一行，不成立就跳过。

注意那行代码**前面的空格（缩进）**——这是 Python 的规矩：缩进进去的代码，才属于这个 if 管。别小看这几个空格，Python 全靠它分清"谁管谁"。

## 让判断更聪明：比较

真实情况里，判断往往来自"比大小"。比如血量低于某个值就报警：

```python
hp = 5

if hp < 6:
    print("屏幕开始变红，快找吃的！")
```

`hp < 6` 是一个**比较**，电脑会算出它成立还是不成立。常用的比较符号有这些：

- `>` 大于、`<` 小于
- `>=` 大于等于、`<=` 小于等于
- `==` 等于（注意是**两个等号**！）
- `!=` 不等于

这里有个新手一定会栽的坑：**判断相等要用 `==`，不是一个 `=`。** 一个等号是上一课的"放进去"，两个等号才是"问一句：它俩相等吗？"

翻译成人话：`=` 是"把右边塞进左边"，`==` 是"左右两个一样吗？"

## 否则呢？else

只处理"成立"还不够，我们常常还要管"不成立"的情况。用 `else`（否则）：

```python
hp = 15

if hp <= 0:
    print("你死了，重生中……")
else:
    print("还活着，继续冒险！")
```

`if` 成立走上面，`else` 兜住剩下所有情况。二选一，一定有一个会执行。

## 好几种情况：elif

如果情况不止两种呢？比如按血量给不同提示，用 `elif`（否则如果）：

```python
hp = 4

if hp <= 0:
    print("你死了……")
elif hp < 6:
    print("危险！血量告急，屏幕变红")
else:
    print("状态良好")
```

把 `if / elif / else` 想象成一排值班保安：从上往下一个个检查，谁先"成立"就放谁过，后面的直接不看了。所以**顺序很重要**——先写最危急的情况。

翻译成人话：`elif` = "要是上面那条不成立，那再看看这条"。

## 真与假：布尔值

你可能注意到了，条件的结果只有两种：**成立**或**不成立**。程序里用两个专门的值表示它们：

- `True`（真，成立）
- `False`（假，不成立）

这种"只有真假两种取值"的东西，叫**布尔值**（Boolean，纪念数学家布尔）。`hp < 6` 算出来的，其实就是一个 True 或 False。

```python
hp = 5
print(hp < 6)    # 打印出 True
print(hp > 10)   # 打印出 False
```

## 一次判断多个条件：and / or / not

游戏里的判断常常要同时看好几件事。比如：**天黑了，而且血量还低**，才特别危险。用 `and`（并且）：

```python
is_night = True
hp = 4

if is_night and hp < 6:
    print("危险的夜晚！赶紧盖房子躲起来")
```

- `and`（并且）：两个条件都成立，才算成立。
- `or`（或者）：只要有一个成立，就算成立。
- `not`（不是）：把真假反过来。

```python
has_sword = False

if not has_sword:
    print("手无寸铁，先别去打怪")
```

翻译成人话：`and` 是"都要满足"，`or` 是"满足一个就行"，`not` 是"反过来"。

## 今天你学会了

- **条件判断**：让电脑先看情况，再决定做不做
- **`if`**：如果……就……（注意缩进）
- **比较符**：`>` `<` `>=` `<=` `==` `!=`
- **`==` 不是 `=`**：两个等号才是"问相等吗"
- **`else` / `elif`**：兜底 / 多种情况，像一排保安从上往下放行
- **布尔值 `True` / `False`**：条件成立与否
- **`and` / `or` / `not`**：并且 / 或者 / 取反

有了判断，你的程序第一次有了"脑子"——它能看情况办事了。
