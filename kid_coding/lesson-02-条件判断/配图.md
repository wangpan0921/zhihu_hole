> 全 8 张图。分工：插画用 AI 提示词；概念图用 excalidraw 逐元素脚本；代码运行图用真实截图。
> 优先级：时间紧只做 3 张必配 —— 图1 封面、图2 if 流程图、图5 血量分级运行截图。

## 图2【概念图·必配】if 流程图（excalidraw）
- **插入位置**：「最简单的判断：if」节，`if in_lava:` 代码之后
- 打开 https://excalidraw.com：
  - 顶部画一个菱形（判断框），里面写 `踩在岩浆里？`。
  - 从菱形画两条箭头：一条标「成立 True」向下指向一个矩形 `扣血 4 点`；一条标「不成立 False」向右指向 `什么都不做`。
  - 顶部标题：`if = 先看条件，成立才执行`。
  - Sloppiness 中间档（手绘感）→ 导出 PNG，白底。

## 图3【概念图·加分】比较符号表 + `=` vs `==`（excalidraw / Canva）
- **插入位置**：「让判断更聪明：比较」节
- 左半：6 个比较符号卡片，每个写符号 + 含义（`>` 大于 / `<` 小于 / `>=` 大于等于 / `<=` 小于等于 / `==` 等于 / `!=` 不等于）。
- 右半：重点对比框——`=`「把右边塞进左边」 vs `==`「左右一样吗？」，用红色高亮这个新手坑。
- 导出 PNG。

## 图4【概念图·加分】if/elif/else 保安示意（excalidraw）
- **插入位置**：「好几种情况：elif」节
- 画三个从上到下排列的"保安岗亭"（矩形），依次写：
  - `if  hp <= 0` → 你死了
  - `elif hp < 6` → 危险
  - `else` → 状态良好
- 左侧一个箭头从上往下贯穿，标注「从上往下检查，谁先成立就放谁过，后面不看」。
- 导出 PNG。

## 图5【运行截图·必配】血量分级提示
- **插入位置**：「好几种情况：elif」节，代码之后
- 在线编辑器（online-python / pythontutor）粘贴运行：
  ```python
  hp = 4
  if hp <= 0:
      print("你死了……")
  elif hp < 6:
      print("危险！血量告急，屏幕变红")
  else:
      print("状态良好")
  ```
- 截「代码 + 输出 `危险！血量告急，屏幕变红`」整屏。字号调大，全系列统一编辑器与配色。

## 图6【概念图·加分】and / or / not 真值示意（excalidraw）
- **插入位置**：「一次判断多个条件」节
- 三个小方块：
  - `and` 并且：画两个都打勾才亮的灯。
  - `or` 或者：一个打勾就亮的灯。
  - `not` 取反：真↔假互换的箭头。
- 顶部标题：`and 都要满足 / or 满足一个 / not 反过来`。
- 导出 PNG。

## 图7【总结卡·加分】今天你学会了（Canva/创客贴）
- **插入位置**：「今天你学会了」节
- 沿用第1课的固定竖版模板，仅改课程编号为「第 2 课」，6 条要点换成：
  - 🧠 条件判断：先看情况再决定
  - ❓ if：如果…就…（注意缩进）
  - ⚖️ 比较符 `> < >= <= == !=`
  - ⚠️ `==` 不是 `=`
  - 👮 else/elif：兜底/多情况
  - 🔗 and / or / not
- 底部品牌栏 + 公众号名。
