## 图2【概念图·加分】5 行 vs 1 行对比（excalidraw）
- **插入位置**：「史蒂夫的新烦恼」→「for 循环长什么样」之间
- 左边：5 行重复的 `print(...)`，用红框标「累、易错、100 只怎么办」。
- 右边：1 行 `for i in range(5):` + 缩进的 print，用绿框标「一句话搞定，改 5→100 即可」。
- 中间一个大箭头从左指向右。顶部标题：`重复的事，交给 for`。
- 导出 PNG。

## 图3【概念图·必配】range 数轴示意（excalidraw）
- **插入位置**：「for 循环长什么样」讲 `range(5)` 处
- 画一条数轴，标出方块 `0 1 2 3 4`（共 5 个，用绿色高亮），在 `5` 的位置画一道红色"止步线"并标「到 5 之前停」。
- 上方标注：`range(5) → 0,1,2,3,4（从 0 开始，5 个）`。
- 再画一行对比：`range(1, 6) → 1,2,3,4,5`。
- 顶部标题：`range：从哪开始、到哪之前停`。强调"从 0 开始"这个坑。
- 导出 PNG。

## 图4【概念图·加分】循环执行流程（excalidraw）
- **插入位置**：「for 循环长什么样」拆解处
- 画一个循环流程：`i 取下一个值` →（还有值吗？）→ 有 → `执行缩进里的代码` → 回到取值；没有 → `结束`。
- 用 range(3) 举例，在旁边列出 i=0、i=1、i=2 三轮分别打印什么。
- 导出 PNG。

## 图5【运行截图·必配】一行顶五行 + 编号
- **插入位置**：「for 循环长什么样」与「i 能拿来干活」处
- 在线编辑器（online-python / pythontutor）运行并截「代码 + 输出」：
  ```python
  for i in range(5):
      print("第", i + 1, "只僵尸出现了")
  ```
- 输出应为"第1只…第5只"。字号调大，全系列统一编辑器与配色。
- 也可用 `./venv/bin/python scripts/kid_coding_images.py --lesson 3` 自动生成本课所有代码/终端图。

## 图6【运行截图·加分】经验累加
- **插入位置**：「i 能拿来干活」累加套路处
- 运行并截图：
  ```python
  total = 0
  for i in range(10):
      total = total + 3
  print("一共获得经验：", total)
  ```
- 输出 `一共获得经验： 30`。

## 图7【总结卡·加分】今天你学会了（Canva/创客贴）
- **插入位置**：「今天你学会了」节
- 沿用系列固定竖版模板，编号改「第 3 课」，6 条要点：
  - 🔁 for：一件事重复做 N 遍
  - 0️⃣ range(n)：0 到 n-1（从 0 开始）
  - 🔢 range(a,b)：a 到 b-1
  - 🅘 循环变量 i：每轮取下一个值
  - ↹ 缩进：缩进的才重复
  - ➕ 累加套路：先 total=0，循环里加
- 底部品牌栏 + 公众号名。
