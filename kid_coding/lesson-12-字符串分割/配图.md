## 图5【运行截图·必配】空手 split() 拆命令

- 打开 https://www.online-python.com，粘贴：

  cmd = "/give steve diamond 64"

## 图8【运行截图·加分】命令翻译器
- **插入位置**：「第五步：命令翻译器」节末尾
- 粘贴以下代码到 online-python.com：
  ```python
  name_zh = {
      "diamond": "钻石",
      "iron":    "铁锭",
      "gold":    "金锭",
      "emerald": "绿宝石",
  }

  cmd = "/give steve diamond 64"

  action, who, what, amount = cmd.split()
  amount = int(amount)

  item_zh = name_zh.get(what, what)

  print(f"要给 {who} {amount} 个 {item_zh}。")
  ```
- 运行输出：
  ```
  要给 steve 64 个 钻石。
  ```
- 截「代码 + 输出」整屏。**这张证明「新旧武器（split + 解包 + int + dict + f-string）组合起来，就是一个小工具」——重要**。
