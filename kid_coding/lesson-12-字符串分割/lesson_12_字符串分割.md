```python
cmd = "/give steve diamond 64"
parts = cmd.split()
print(parts)
print(len(parts))
print(parts[0])
print(parts[-1])
```

（提示：`cmd.split()` 会**沿着空格**把这句话切成一小段一小段；结果不是一整句，而是一个**列表**——第 5 课学过的老朋友。）

## 一句话接主线

家园盖好了、仓库贴上了价签，史蒂夫下一步要**学会发号施令**——聊天框敲一句命令，程序自动理解并执行。**能读懂玩家输入**这一步，是所有游戏、工具、聊天机器人的入门槛。今天带你迈过去。

## 用「一坨字符串」发命令，好像哪里不对

你在游戏里敲了这么一句：

```
/give steve diamond 64
```

肉眼一扫就懂：**给** / **谁** / **啥** / **多少**。可对电脑来说，`"/give steve diamond 64"` 只是**一整串字符**——它并不知道空格是「分界线」、也不知道最后一个 `64` 是数字。

想到用第 7 课学过的 `in` 和切片？行是行——但每次都得**数第几个空格在哪、字符串从哪切到哪**，命令一改长度就崩。真实项目里没人这么干。

Python 早就替你想好了——**`split`**：**沿着一个「切刀」把长字符串剁成一段段**，结果自动打包成一个**列表**。翻译成人话：**「按某个记号，把长句子切成好几段」**。

## 第一步：认识 split（I-do）

最常用的一招——**空手 `split()`（不带参数）**：默认**按「空白」**切，一段段收进列表：

```python
cmd = "/give steve diamond 64"
parts = cmd.split()
print(parts)
```

输出：

```
['/give', 'steve', 'diamond', '64']
```

三件事一次讲清：

- **`.split()`** 是**字符串的方法**——写在字符串后面加一个点，跟第 7 课的 `.replace()` 一家。翻译成人话：**「字符串对自己做的动作」**。
- **默认按「空白」切**——一个空格、多个空格、甚至换行、Tab，通通算分界线。**多余的空格会被自动吞掉**，你不必洁癖到「必须只有一个空格」。
- **返回值是一个列表**——四段字符串排队站好，索引依然从 0 开始。**列表所有本领这里都能用**：`len(parts)` 数几段、`parts[0]` 取第一段、`parts[-1]` 取最后一段。

顺手把开场那道题揭晓：`parts` 是 `['/give', 'steve', 'diamond', '64']`；`len(parts)` 是 `4`；`parts[0]` 是 `'/give'`；`parts[-1]` 是 `'64'`（**注意是带引号的字符串**，不是数字 64——这个坑第四步细说）。

## 第二步：给切刀换个刃（I-do）

有时候分界线不是空格。比如你想把坐标 `"100,64,-200"` 切成 x / y / z：

```python
pos = "100,64,-200"
xyz = pos.split(",")
print(xyz)
```

输出：

```
['100', '64', '-200']
```

**`split(切刀)`** 里放什么，就沿着什么切。逗号、冒号、竖线、连字符——**你说了算**。

再比如聊天里的 `steve:hello:world`（冒号做分隔）：

```python
msg = "steve:hello:world"
who, *rest = msg.split(":")
print(who)     # steve
print(rest)    # ['hello', 'world']
```

（这里的 `*rest` 是 Python 的「打包剩下的」小魔法——**第一段拿一个名字接、剩下的都塞进一个列表**。你只需要知道有这个玩法，暂时别死抠原理。）

顺手记一条**反向咒语**——**`"分隔符".join(列表)`**：把一堆字符串**用分隔符黏回一整串**。它是 `split` 的镜像：

```python
xyz = ["100", "64", "-200"]
back = ",".join(xyz)
print(back)    # 100,64,-200
```

**`split` 拆、`join` 合**——这两个搭档以后写日志、写文件、写命令，天天见。

## 第三步：把每一段「安排」到自己的位置（I-do）

现在史蒂夫想让 `parts` 里的每一段各归各位——**动作 / 收货人 / 物品 / 数量**：

```python
cmd = "/give steve diamond 64"
parts = cmd.split()

action = parts[0]     # '/give'
who    = parts[1]     # 'steve'
what   = parts[2]     # 'diamond'
amount = parts[3]     # '64'  ← 注意，这里还是字符串

print("动作：", action)
print("收货人：", who)
print("物品：", what)
print("数量：", amount)
```

`parts[0]` 到 `parts[3]` 一段段取出来，很清楚。可 Python 还有一招**更省心**：**一次接一整排**。这个动作叫**「解包」（unpacking）**——翻译成人话：**「左边写几个名字，右边就把列表拆成几份分给它们」**。

```python
cmd = "/give steve diamond 64"
action, who, what, amount = cmd.split()
print(action, who, what, amount)
```

输出：

```
/give steve diamond 64
```

一行代码搞定四个变量——**优雅、清楚、不容易错**。**唯一的规矩**：左边名字的**个数**必须跟右边列表的**长度**对上，不然会崩：

```
ValueError: not enough values to unpack (expected 4, got 3)
```

翻译成人话：**「说好要 4 个、结果只给了 3 个」**。以后看到 `ValueError`，先低头数一下两边个数——十有八九是这里出问题。

**跟第 5 课的 `enumerate`、第 11 课的 `.items()` 一起想想**——左边写几个名字接住右边，Python 里到处都是这个套路。**一次拿几个就写几个名字**，这句话记牢，字典遍历、`split` 结果全都通杀。

## 第四步：数字还是字符串？—— 别踩这个坑（I-do）

刚才 `amount = parts[3]` 拿到的是 `'64'`（**带引号的字符串**），**不是**数字 64。信奥赛里最爱送分的坑之一：**忘了把字符串转成数字，直接拿去算数**。

```python
cmd = "/give steve diamond 64"
parts = cmd.split()
amount = parts[3]         # '64'
print(amount + 1)         # ❌ 直接崩：TypeError
```

报错：

```
TypeError: can only concatenate str (not "int") to str
```

**`TypeError`** 就是**「类型不对，操作对不上」**——你让「一坨文字」跟数字相加，Python 说没道理啊。

第 1 课埋过的伏笔，今天正式挖出来——**`int()`**：**把「看起来是数字的字符串」转成真正的数字**。

```python
amount = int(parts[3])    # 64  ← 真正的数字了
print(amount + 1)         # 65  ✅
```

一条**铁律**：**从 `input`、`split`、文件里读进来的数字，默认都是字符串——要参与算术，先 `int()`（整数）或 `float()`（小数）**。

## 第五步：拼起来——命令翻译器（I-do）

现在把上面所有招式串成一个**命令翻译器**——**输入一条命令，输出人话解释**，顺手用上第 11 课的字典：

```python
# 物品中文名对照表（复用第 11 课的字典）
name_zh = {
    "diamond": "钻石",
    "iron":    "铁锭",
    "gold":    "金锭",
    "emerald": "绿宝石",
}

cmd = "/give steve diamond 64"

action, who, what, amount = cmd.split()
amount = int(amount)

item_zh = name_zh.get(what, what)   # 查不到就用英文原名兜底

print(f"要给 {who} {amount} 个 {item_zh}。")
```

输出：

```
要给 steve 64 个 钻石。
```

看清这台「翻译器」用了几件武器：

- **`split`**——把命令切成四段（**本课新招**）。
- **解包**——一行把四段发到四个变量（**本课新招**）。
- **`int`**——把 `'64'` 变成数字 `64`（**第 1 课伏笔**）。
- **`dict.get(键, 默认值)`**——查中文名，查不到就用英文原名（**第 11 课刚学**）。
- **`f"..."`**——**f-string**，字符串里直接嵌变量，写法 `f"...{变量}..."`。翻译成人话：**「把大括号里的东西替换成变量的值」**。第 7 课字符串里点过头，今天正式上手。

**新旧武器组合起来，第一台「小工具」诞生了**。以后所有「解析命令 / 解析用户输入 / 解析日志」的活，都是这条套路的变形。

## 一起改改看（We-do）

轮到你上场——每一改都**先预测、再运行**。

**改动 1**：把命令改成 `"/give   steve   diamond   64"`（**中间塞很多空格**）。**预测**：`parts` 会变成什么？会不会多出一堆空字符串？

> **揭晓**：**结果一模一样**——`['/give', 'steve', 'diamond', '64']`。**`split()` 不带参数时，会把「连续的空白」当成一整个分隔符**——多打的空格自动被吞掉，脏输入也能扛。**但**如果你写成 `split(" ")`（**明确传一个空格**），情况就变了——它会一板一眼地按「每一个空格」切，中间就冒出一堆空字符串 `''`。**空手 `split()` 更宽容，写死 `split(" ")` 更死板**。信奥赛读题目输入时，**空手 `split()` 是首选**。

**改动 2**：把命令改成 `"/give steve diamond"`（**故意漏掉数量**），保持 `action, who, what, amount = cmd.split()` 不变。**预测**：会输出啥？

> **揭晓**：直接崩——`ValueError: not enough values to unpack (expected 4, got 3)`。**说好要 4 个、给了 3 个**——就是第三步讲过的那个坑。**修法**：先用 `if len(parts) == 4:` 检查一下再解包，或者用**第 11 课的老朋友 `.get`** 的思路——**兜底**。

**改动 3**：把 `amount = int(amount)` **删掉**，再跑 `f"要给 {who} {amount} 个 {item_zh}。"`。**预测**：字符串还能拼吗？

> **揭晓**：**能拼、不崩、但语义变了**——`amount` 还是字符串 `'64'`。f-string 只是**把变量的值贴过去**，字符串就贴字符串、数字就贴数字，肉眼看起来一样。**但你后面想 `amount * 2` 就崩**。**铁律：读进来先转型、算完再显示**。

**改动 4（组合拳）**：命令改成 `"/give steve diamond 32 rare"`（**多了一段稀有度**），想只取前四段、把「rare」丢进一个 `extras` 里。

> **提示**：用第二步见过的 `*` 小魔法：
>
> ```python
> action, who, what, amount, *extras = cmd.split()
> ```
>
> 前四段一一对应，剩下的（**哪怕零段、哪怕好几段**）全打包成一个列表 `extras`。**预测** `extras` 是什么？跑一下验证——你现在会**主动利用**「打包剩下的」这个小魔法了。

改完回头想一件事：**拿到用户的一坨输入 → `split` 拆开 → 各归各位 → `int` 转型 → 用字典翻译 → f-string 拼输出**——这条流水线，你会在**所有**「读输入、写工具」的题里反复用到。**信奥赛第一题读输入，八成就是这条流水线**。

## 今天你学会了

- **`split(切刀)`**：**沿着「切刀」把字符串切成一段段**，返回**一个列表**。**列表所有本领都能接着用**。
- **空手 `split()`**：默认按**任意空白**切，**连续空格会被吞掉**——读用户输入的首选。
- **`split(",")` / `split(":")` / `split("|")`**：分隔符**你说了算**。
- **反向操作**：**`"分隔符".join(列表)`**——把列表用分隔符黏回一整串。**`split` 拆、`join` 合**。
- **解包**：`a, b, c = 列表`——**左边写几个名字，右边就拆成几份**。个数对不上会崩 `ValueError`。剩下的可以用 `*rest` 打包。
- **`int(字符串)` / `float(字符串)`**：**从 `input`、`split`、文件读进来的数字，参与算术前必须先转型**——**忘了转型，`TypeError` 送分**。
- **`f"...{变量}..."` 的 f-string**：字符串里直接嵌变量，`f` 打头、大括号包变量名。
- **一条流水线**：**输入 → split → 解包 → int → dict 翻译 → f-string 输出**。所有「读命令、读日志、读用户输入」的题，都是这条流水线的变形。

**一句话总结**：**`split` 是电脑的剪刀**——把一句话按你说的记号剁成好几段，剩下的事就交给列表和字典。以后凡是「一坨长字符串要拆开看懂」的活，先想 `split`。

## 课后挑战

**🟢 基础关**

给下面这条命令写一个解析器：

```python
cmd = "/tp steve 100 64 -200"    # 传送 steve 到坐标 (100, 64, -200)
```

要求打印：

```
传送 steve 到坐标 (100, 64, -200)
```

> **小提示**：一次 `split()` 拿到 5 段；**坐标要转成数字**（`int`）才能后续做距离计算——虽然这次先只打印，但**转型习惯从今天养成**。用 f-string 把结果拼出来。

**🔴 进阶关**

聊天服务器一次发来**一整段日志**，每一行是一条命令，用换行符 `\n` 隔开：

```python
logs = """/give steve diamond 64
/give alex iron 12
/give steve gold 8
/give steve diamond 16"""
```

写一个**统计器**——统计**每个玩家一共收到了多少件物品**，用字典存结果。期望输出（顺序可以不同）：

```
steve: 88
alex: 12
```

> **小提示**：先 `logs.split("\n")` 把整段拆成**每行一条命令**的列表；再对**每一条**继续 `split()` 拆四段；数量记得 `int`。**累加到字典**的经典写法——**第 11 课的老朋友 `.get` 又来了**：
>
> ```python
> total = {}
> total[who] = total.get(who, 0) + amount
> ```
>
> 翻译成人话：**「他之前拿过多少？没拿过就当 0，加上这次的量再放回去」**——这行代码是**「用字典做统计」的万能公式**，以后统计词频、统计得分、统计出现次数，全都是它。

**加分挑战**：把物品英文名（`diamond`、`iron`、`gold`）用第 11 课的字典翻译成中文，输出类似 `steve: 钻石 80 个、金锭 8 个 —— 共 88 件`。这次你要维护的**不只是一个数字**，而是**每个玩家 → 一份物品明细**——**字典里装字典**（`total[who][item] = 数量`），第 11 课的「嵌套」套路今天有实战场景了。
