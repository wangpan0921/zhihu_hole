## 每日产出与自动化流程

每个课程目录 `kid_coding/lesson-NN-主题/` 里有三类文件：

| 文件 | 谁产出 | 说明 |
|------|--------|------|
| `article.md` | 自动化生成 | 文章草稿正文（首行 `# 标题`，符合公众号 Markdown→HTML 渲染子集） |
| `配图.md` | 自动化生成 | 本篇每张图的制作方法（AI 提示词 / excalidraw 脚本 / 截图代码，注明插入位置） |
| `lesson_NN_主题.md` | **使用者手动定稿** | 基于上面两份草稿整理出的最终文章。它的存在 = 该课已定稿 |

**自动生成节奏**（每天 07:10，`scripts/kid_coding_next.py` 判断 + 定时 agent 执行）：

1. 找编号最大的课程目录（最新一课）。
2. 若其中已有定稿文件 `lesson_*.md` → 说明该课已定稿 → 生成「下一课」的 `article.md` + `配图.md`（放进新目录 `lesson-(NN+1)-主题/`）。
3. 若还没有定稿文件 → 跳过，不生成（避免草稿堆积，等你先定稿当前这课）。

**你的动作**：审阅 `article.md` 和 `配图.md`，配好图、按需润色后，在同目录另存为 `lesson_NN_主题.md`（定稿）。定稿一出现，次日 07:10 就会自动生成下一课草稿。

**生成视频**：对任意一课说「生成第 N 课的视频」，调用 `scripts/kid_coding_video.py --lesson N`，会读取该课文章（优先定稿 `lesson_NN_*.md`，否则 `article.md`）生成讲解视频，输出到该课目录。
