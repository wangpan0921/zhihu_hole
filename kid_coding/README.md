# 跟着史蒂夫，从零打通信奥赛之路 · 系列大纲

> 公众号少儿编程连载的总规划文档。主题贯穿《我的世界》，目标对齐信息学奥赛（CSP-J/S、NOIP）。
> 每天产出一篇：文章正文 + 配图制作方法，放在本文件夹对应的 `lesson-xx-主题/` 子目录里。

## 内容路线总览

- **语言路线**：Python 入门（培养兴趣、降低门槛）→ 语言迁移专题 → C++ 备赛（信奥赛只认 C/C++）。
- **故事线**：见下节《系列故事线》——史蒂夫从零求生，每学一个编程本领就解锁一项生存 / 建造能力。
- **风格锚点**：先猜后讲、游戏场景引入、每个术语跟一句「翻译成人话」、渐进放手（I-do 示范 → We-do 一起改 → You-do 自己做）。
- **每篇结构**：上期回顾（一句话）→ 提问 / 先猜猜看开场 → 游戏场景引入 → 讲解（I-do）→ 一起改改看（We-do：改一处、先预测再验证）→ 「今天你学会了」总结卡 → 分档课后挑战 🟢🔴（You-do）→ 下期预告。

## 系列故事线

主线：**史蒂夫的生存进化**。史蒂夫初到《我的世界》，一无所有；每掌握一个编程本领，就解锁一项新的生存 / 建造 / 探险能力，一步步从新手打造出自己的自动化基地，最终「通关」——走上信奥赛赛场。每课开头用一句话把当课知识点接到这条主线上，给读者追更的连续感。

- **入门关（活下来）**：记录家底（变量）→ 遇险决策（条件）→ 重复劳作（循环）→ 收纳整理（列表）→ 打造工具（函数）…… 史蒂夫学会在世界里稳稳活下来。
- **进阶关（造起来）**：铺地图、开自动商店，把重复的事交给程序。
- **算法关（想明白）**：探洞、走迷宫、算最优攻略——学会「聪明地做决定」。
- **数据结构关（搭系统）**：技能树、传送门网络，搭建更复杂的世界。
- **迁移 + 实战（上赛场）**：换上专业装备 C++，去打真正的信奥赛。

## 每日产出与自动化流程

每个课程目录 `kid_coding/lesson-NN-主题/` 里有三类文件：

| 文件 | 谁产出 | 说明 |
|------|--------|------|
| `article.md` | 自动化生成 | 文章草稿正文（首行 `# 标题`，符合公众号 Markdown→HTML 渲染子集） |
| `配图.md` | 自动化生成 | 本篇每张图的制作方法（AI 提示词 / excalidraw 脚本 / 截图代码，注明插入位置） |
| `lesson_NN_主题.md` | **使用者手动定稿** | 基于上面两份草稿整理出的最终文章。它的存在 = 该课已定稿 |

**自动生成节奏**（每天 07:10，`scripts/kid_coding_next.py` 判断 + 定时 agent 执行）：

1. 找编号最大的课程目录（最新一课）。
2. 若其中已有定稿文件 `lesson_*.md` → 说明该课已定稿 → 生成「下一课」的 `article.md` + `配图.md`（放进新目录 `lesson-(NN+1)-主题/`）。
3. 若还没有定稿文件 → 跳过，不生成（避免草稿堆积，等你先定稿当前这课）。

**你的动作**：审阅 `article.md` 和 `配图.md`，配好图、按需润色后，在同目录另存为 `lesson_NN_主题.md`（定稿）。定稿一出现，次日 07:10 就会自动生成下一课草稿。

**生成视频**：对任意一课说「生成第 N 课的视频」，调用 `scripts/kid_coding_video.py --lesson N`，会读取该课文章（优先定稿 `lesson_NN_*.md`，否则 `article.md`）生成讲解视频，输出到该课目录。
