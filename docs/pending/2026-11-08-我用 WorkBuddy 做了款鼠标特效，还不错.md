# 我用 WorkBuddy 做了一个《我的世界》鼠标特效

## 一个临时想到的小需求

儿子很喜欢玩游戏，其中最喜欢的就是《我的世界》。昨天晚上睡觉前，他突然跟我说，想要一个“酷一点的鼠标特效”。

第二天早上 7 点，我醒来后没了睡意，索性就拿这个小需求来试试 WorkBuddy。

整个过程比我预想得更省事：除了询问和比较方案，我真正用来描述需求的核心指令只有两条。大约 20 分钟后，WorkBuddy 就给出了一个可以直接运行的版本。它不仅完成了效果，还一并说明了启动方式、已知限制和后续可以改进的方向。

## 先搞清楚 Windows 光标是怎么回事

其实，我之前并不知道 Windows 上的鼠标特效应该怎么做。所以我没有一上来就指定技术方案，而是直接把想法告诉它，让它先帮我分析。

![向 WorkBuddy 描述鼠标特效需求](workbuddy.png)

WorkBuddy 很快解释了 Windows 默认光标的工作方式，也说明了“替换系统光标”和“在光标周围叠加视觉效果”并不是一回事。

![WorkBuddy 解释 Windows 鼠标机制](workbuddy-1.png)

接着，它给出了几种实现思路。面对这些技术方案，我一时也分不清它们各自的优缺点，于是又追问了一句：这几种方案到底有什么区别，哪种更适合我现在的需求？

![追问几种实现方案的区别](workbuddy-2.png)

它没有只给一堆技术名词，而是把几种方案的实现成本、效果上限和适用场景做了对比。这一步对我来说很有用：我不需要先成为 Windows 图形编程专家，也能根据实际需求做出选择。

![WorkBuddy 对比不同的实现方案](workbuddy-3.png)

## 从想法到可运行的小工具

想清楚方向后，我只需要把偏好补充给它：效果要有《我的世界》的感觉，看起来要够酷，同时不要影响鼠标的正常使用。

![确定《我的世界》风格的鼠标效果](workbuddy-4.png)

接下来基本就是 WorkBuddy 自己在忙了。它选择了一个相对轻量的实现：保留 Windows 原有的鼠标箭头，再通过透明叠加层，在鼠标周围绘制光环、粒子和像素风格的方块。这样既能做出明显的视觉效果，又不会接管鼠标点击。

最终，它交付了三个文件：

- `minecraft_cursor.py`：鼠标特效的主程序；
- `启动.bat`：日常使用时双击即可启动；
- `调试启动.bat`：带控制台运行，出错时可以保留日志，方便排查。

它还完成了基本验证，确认光环、粒子和面板能正常显示，程序运行期间也没有出现异常日志。同时，它也把已知边界说得很清楚：某些独占全屏游戏可能会遮住叠加层；目前版本只是在默认鼠标外增加特效，并没有替换系统鼠标本身。

![WorkBuddy 交付的程序、启动脚本和使用说明](workbuddy-5.png)

## 实际效果

这就是最后跑起来的样子。当鼠标移动时，周围的像素方块和粒子会跟着变化，整体风格与《我的世界》的视觉元素比较搭。它还谈不上一个完整产品，但作为 20 分钟内完成的原型，效果已经超出了我的预期。

![《我的世界》风格鼠标特效演示](20261108082701_rec_.gif)

## 我对这次体验的看法

这次体验最打动我的，并不只是 WorkBuddy “能写代码”。

更关键的是，当我只有一个比较模糊的想法，又不了解具体技术时，它能先帮我把问题拆开，说清楚可选方案和各自的取舍；等我做完选择后，它又能继续完成编码、测试和使用说明。最后拿到的不是一段需要我自己收尾的代码，而是一个能启动、能调试，也说清了限制的小工具。

当然，它还有很多可以继续完善的地方：比如把默认箭头换成像素镐或草方块，将 Python 程序打包成无需安装环境的 `exe`，或者加入更多可切换的主题。不过，对于一个早上临时起意的小项目来说，这个结果已经很不错了。

以前，像“给儿子做个鼠标特效”这样的念头，很可能只会停留在口头上。现在，从一个想法到一个可以亲手试玩的原型，可能真的只需要二十分钟。
