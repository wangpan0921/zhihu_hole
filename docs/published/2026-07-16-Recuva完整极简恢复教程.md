# Recuva 完整极简恢复教程：Shift+Delete 文件专用

在 Windows 上误删文件时，最让人紧张的一种情况是：

```text
Shift + Delete
```

因为这种删除不会先进回收站，文件看起来像是“直接没了”。但这不代表一定救不回来。只要原来的数据还没有被新数据覆盖，就还有机会恢复。

这篇只讲一个很具体的场景：

> Windows 电脑上误用 Shift+Delete 删除了文件，想用 Recuva 尽快尝试恢复。

先说结论：恢复成功率主要取决于两个因素，一是删除后有没有继续往原盘写入数据，二是硬盘类型。如果是机械硬盘，且删除后没有继续大量写入，成功率会高一些；如果是 SSD，并且系统已经触发 TRIM，恢复难度会明显增加。

## 一、先做这三件事

误删后，先不要急着到处安装软件、复制文件。最重要的是减少对原盘的写入。

建议按下面规则处理：

1. 如果文件原来在 `D:` / `E:` / `F:` 盘，Recuva 尽量安装到 `C:` 盘。
2. 如果文件原来就在 `C:` 盘，不建议继续往 `C:` 盘安装软件，最好换另一台电脑、U 盘工具，或让专业人员处理。
3. 恢复出来的文件必须保存到别的盘或 U 盘，不要保存回原来的盘。

原因很简单：删除文件后，系统通常只是把这块空间标记为“可以重新使用”。如果你继续往同一个盘写入新数据，原来的内容就可能被覆盖。一旦覆盖，普通软件基本就救不回来了。

所以恢复文件时要记住一句话：

> 扫描可以扫原盘，恢复结果不要写回原盘。

## 二、去哪里下载 Recuva

Recuva 是 Piriform / CCleaner 旗下的文件恢复工具。建议只从官方页面下载，避免下载到带捆绑或被修改过的安装包。

官方产品页：

```text
https://www.ccleaner.com/recuva
```

官方下载页：

```text
https://www.ccleaner.com/recuva/download
```

如果页面里有免费版，普通误删恢复先用免费版尝试即可。

下载和安装时注意两点：

- 不要把 Recuva 安装到丢失文件所在的盘。
- 安装过程中如果出现额外软件推荐，注意取消不需要的勾选。

比如文件原来在 `D:` 盘，Recuva 可以装到 `C:` 盘；文件原来在 `C:` 盘，就不要继续往 `C:` 盘安装，避免覆盖数据。

## 三、开始扫描：按向导一步一步来

安装完成后，打开 Recuva。它通常会弹出恢复向导，新手直接跟着向导走就可以。

### 1. 选择文件类型

Recuva 会问你要恢复什么类型的文件，例如：

- 图片
- 文档
- 视频
- 音乐
- 邮件
- 全部文件

如果你明确知道丢的是照片，就选图片；如果你不确定，选全部文件。

文件类型选得越具体，结果越容易筛选；选全部文件更全面，但扫描结果可能会很多。

### 2. 选择原来的文件位置

下一步会让你选择文件原来在哪里。

如果记得位置，优先选择：

```text
在特定位置
```

然后定位到原来的磁盘或文件夹。

例如文件原来在：

```text
D:\3-zhihu
```

就选择这个目录或至少选择 `D:` 盘。

如果完全不记得位置，可以选择：

```text
我不确定
```

但这样会扫描更大范围，速度会慢很多，结果也会更杂。

### 3. 勾选深度扫描

Shift+Delete 删除的文件不在回收站里，普通快速扫描有时找不到。建议勾选：

```text
启用深度扫描
```

深度扫描会更慢，几十分钟甚至更久都正常，尤其是硬盘很大、文件很多的时候。

这里不要频繁中断，也不要一边扫描一边往原盘复制新文件。

## 四、看扫描结果：绿色、黄色、红色是什么意思

扫描完成后，Recuva 会列出找到的文件。列表里通常会用颜色表示可恢复状态。

大致可以这样理解：

| 颜色 | 含义 | 建议 |
|---|---|---|
| 绿色 | 状态较好，恢复概率高 | 优先恢复 |
| 黄色 | 文件可能部分损坏 | 可以尝试，恢复后要打开检查 |
| 红色 | 数据可能已被覆盖 | 恢复概率很低 |

不要只看文件名，还要看大小、路径、修改时间。如果软件支持预览，也可以先预览一下。

常见筛选思路：

- 文件名还在：直接按文件名找。
- 文件名丢失：按文件类型、大小、修改时间筛选。
- 文件很多：先恢复最重要的一小批，不要一次性全选。

## 五、恢复时一定要选别的盘

找到要恢复的文件后，勾选它们，点击右下角的：

```text
恢复
```

这时会让你选择保存位置。

这里最重要：

> 不要保存回原来的盘。

例如文件原来在：

```text
D:\3-zhihu
```

恢复时就不要选 `D:` 盘。可以选择：

```text
C:\Recovered
```

或者外接 U 盘：

```text
U:\Recovered
```

如果恢复结果保存回原盘，新的文件写入可能会覆盖还没恢复出来的数据，导致后续恢复变差。

恢复完成后，先打开文件检查：

- 文档能不能正常打开；
- 图片能不能预览；
- 视频能不能播放；
- 压缩包能不能解压；
- 代码文件内容是否完整。

能打开不代表 100% 完整，重要文件最好再多检查几处内容。

## 六、哪些情况可能救不回来

Recuva 不是万能的。下面几种情况恢复概率会明显降低。

### 1. 原位置已经被新数据覆盖

如果删除后你继续在同一个盘：

- 下载文件；
- 安装软件；
- 解压压缩包；
- 复制大量数据；
- 运行会大量写入缓存的程序；

原来的数据就可能被覆盖。覆盖后，普通恢复软件通常无能为力。

### 2. SSD 已经触发 TRIM

很多 SSD 会启用 TRIM。简单理解，TRIM 会告诉硬盘：这些被删除的数据块已经不用了，可以清理。

一旦清理完成，即使扫描软件还能看到文件名，也可能无法恢复真实内容。

所以 SSD 上误删文件时，恢复窗口通常更短。不要反复重启、安装软件、复制文件，越早处理越好。

### 3. 扫描结果全是红色，或者预览打不开

如果扫描出来的目标文件都是红色，或者恢复后打不开、内容乱码，大概率说明数据已经不完整。

这种情况下可以再尝试：

- 缩小扫描范围重新扫；
- 勾选深度扫描重新扫；
- 换另一个恢复工具交叉验证；
- 如果文件非常重要，停止继续操作，找线下专业数据恢复。

## 七、一个最短操作清单

如果你只想按步骤操作，可以记这个版本：

1. 停止往丢失文件所在盘写入新数据。
2. 从官方页面下载 Recuva。
3. 把 Recuva 安装到别的盘。
4. 打开向导，选择文件类型。
5. 选择文件原来的位置。
6. 勾选深度扫描。
7. 等待扫描完成。
8. 优先恢复绿色文件。
9. 恢复结果保存到别的盘或 U 盘。
10. 打开恢复出的文件确认是否完整。

## 八、小结

Shift+Delete 删除文件后，第一反应不要是继续乱点、乱装、乱复制，而是先保护现场。

Recuva 的使用并不复杂，真正决定成败的是这几条：

- 删除后越少写入原盘，恢复机会越大。
- Recuva 不要安装到丢失文件所在盘。
- 深度扫描更慢，但更适合 Shift+Delete 场景。
- 恢复出来的文件一定要保存到别的盘。
- SSD 如果触发 TRIM，恢复成功率会明显下降。

如果文件只是普通资料，可以先按这篇流程自己尝试；如果是非常重要的合同、照片、项目源码，尤其还在 SSD 上，建议少操作，尽早找专业数据恢复。
